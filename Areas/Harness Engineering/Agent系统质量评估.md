
Agent 评测，根本不只是准确率，端到端任务成功率，只是最终结果，不是过程质量。

Agent是多步决策系统，都会影响最终决策
结果对，不代表每一步对，偶然成功，会掩盖系统缺陷


核心评估模型：
决策轨迹：证明每一步决策都对，数学上我们算Trajectory Match Score,.EditDistance(实际轨迹，
最优轨迹)/最优路径长度。偏差越小，轨迹越接近最优决策链
工具选择：Tool Selection Accuracy：选对工具的概率 Tool Argument F1：参数填写的准确率和召回率综合得分。
执行效率：把“完成率”和“耗时”放在一起看，快且对才更好。笔记里提到可以用“完成率除以平均延迟”来做一个归一化效率得分。
