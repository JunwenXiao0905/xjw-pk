# 工作日志

生成简明工作日志，从 git commit 和对话上下文提炼，用长难句串联。

## 输入来源

1. **Git commit** — `git log --since="$(date +%Y-%m-%d) 00:00:00" --oneline`
2. **对话上下文** — 决策、难点、排查过程
3. **用户补充** — 预览后可调整

## 输出格式

纯编号列表，无标题、无分隔线、无注释：

```
1. 长难句描述工作内容，自然融入技术难度和工作量。
2. 长难句描述下一项工作。
...
```

## 句子风格

- 单句串联：「做什么 + 怎么做 + 难点/工作量」
- 技术难度：「定位」「涉及」「排查」「攻关」
- 工作量：「跨」「联动」「多轮」「覆盖」

## 执行步骤

1. 获取今日 commit
2. 从对话提炼：问题发现、方案决策、失败尝试
3. 合并相关 commit（同一功能），生成长难句
4. 输出预览，等待确认或调整

## 禁止项

- ❌ 日期标题、「工作日志」标题
- ❌ `---` 分隔线
- ❌ 底部注释、Generated by 说明
- ❌ 分节标题（功能开发/问题修复）

## 示例

```
1. 修复点图层点击弹窗无法显示的问题，通过排查发现 hover overlay 拦截了场景拾取，在 LEFT_CLICK 处理中增加检测逻辑实现点击穿透。
2. 设计品牌配置系统，确立 libs/apps 双文件独立架构，libs 承载天地图水印，apps 承载项目标题与 Logo，影响 6 处组件。
3. 修正 Dockerfile 与 README 路径引用错误，完成 API v0.5.6 与 Web v0.5.8 镜像构建并推送。
```

## 边缘情况

| 场景 | 处理 |
|------|------|
| 无 commit | 仅用对话，不足则提示 |
| Git 失败 | 跳过，仅用对话 |
| 对话为空 | 仅用 commit message |
| 指定日期 | 支持「昨天」「本周」「上周」
