# Update Workflow

## 处理顺序

更新一个赛道时，默认按这个顺序：

1. 找现有结构
2. 分类新材料
3. 放入证据池或对应主文档
4. 回写结论
5. 检查是否影响未来预期、进入路径、投资映射

不要把“收集资料”和“下结论”混成一步。

## 新材料分类

遇到新材料时，先判断它属于哪一类：

- `行业证据`：政策、产业报告、标准、融资、量产、出货
- `技术证据`：模型、仿真、控制、感知、部署、论文落地
- `场景证据`：订单、试点、交付、招标、行业案例
- `玩家证据`：公司、实验室、创新中心、高校平台的新动作
- `本地证据`：成都及周边学校、公司、研究所、项目、招聘
- `进入路径证据`：学校分数、考试科目、培养方案、岗位要求
- `投资证据`：财报、基金持仓、ETF、产业链受益线索

## 什么时候更新哪篇

### 更新 `11-产业结构与价值链`

当新材料说明：

- 某个环节变重要了
- 某个瓶颈被缓解或强化了
- 价值向上下游重新分配了

### 更新 `20-玩家图谱`

当新材料说明：

- 某个玩家融资、量产、换路线、签大单、开放平台
- 某个本地平台开始值得长期跟踪

### 更新 `13-商业化场景`

当新材料说明：

- 某个场景开始真交付
- 某个场景依然停留在展示
- 场景成熟度排序需要变化

### 更新 `14-未来预期`

当新材料说明：

- 行业节奏变快或变慢
- 关键催化剂出现
- 风险条件发生变化

### 更新 `30-考研与进入路径`

当新材料说明：

- 学校新增或调整专业方向
- 复试线、考试科目、培养路径变化
- 岗位能力要求变化

### 更新 `40-投资映射`

当新材料说明：

- 某个环节的受益逻辑强化或削弱
- 市场风格对赛道定价发生变化
- 某类基金、ETF 或上游公司更值得观察

## 写作约束

### 结论写法

主文档优先写：

- 现阶段判断
- 依据
- 对用户的意义

不要只贴链接，不要只写“值得关注”。

### 预测写法

预测至少包含以下其中两项：

- 时间范围
- 催化剂
- 风险
- 失效条件

### 用户视角

默认读者不是行业分析师，也不是基金经理。因此要主动解释：

- 这件事为什么重要
- 它和读研、就业、投资观察有什么关系
- 它更像长期变量还是短期噪音

## 具身智能的默认重心

如果赛道是 `具身智能`，默认优先关注：

- 真机落地，而不是只看模型叙事
- 工业、巡检、物流、康复、服务等现实场景
- 成都本地学校、研究平台和产业机会
- 控制、感知、SLAM、仿真、部署等可转化能力

除非用户明确要求，否则不要把重心过度放在“纯人形概念热度”。
