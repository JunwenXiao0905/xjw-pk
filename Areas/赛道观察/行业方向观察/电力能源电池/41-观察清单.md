# 41-观察清单

持续跟踪电力能源电池赛道变化的信号清单。

## 政策

- [ ] 各省容量电价政策是否全面落地（目前仅湖北、甘肃等少数省份明确，其他省份待跟进）
- [ ] 新型储能规模化建设专项行动方案（2025-2027）执行进度
- [ ] "算电协同"细则出台及数据中心配储实际落地情况
- [ ] 工信部对储能低水平产能重复建设的遏制效果
- [ ] 海外市场（欧洲、中东、东南亚）对储能产品的贸易政策变化
- [ ] 四川省/成都市新能源和储能产业专项支持政策

## 价格与市场信号

- [ ] 碳酸锂价格走势（跌破15万或突破25万均为拐点信号）
- [ ] 储能系统中标均价变化（0.6元/Wh以下是关键观察线）
- [ ] 各省峰谷电价差变化趋势
- [ ] 系统运行费（"过路成本"）对储能收益率的实际影响
- [ ] 钠电电芯成本和出货价格变化

## 排产与出货

- [ ] 月度电池排产量（宁德时代/比亚迪/亿纬锂能）
- [ ] 储能电池出货量季度数据（GGII/CNESA）
- [ ] 逆变器出口数据（阳光电源/德业股份）
- [ ] 钠电池实际出货量（2026年目标30GWh能否兑现）

## 技术与量产

- [ ] 500Ah+储能大电芯渗透率（2026年目标约15-20%）
- [ ] 钠电成本能否在2年内降至 0.3-0.4 元/Wh
- [ ] 半固态电池装车节奏（蜂巢/宁德凝聚态2026Q3-Q4）
- [ ] 全固态电池示范线进展（2027年时间表是否有变）
- [ ] 液流电池/压缩空气储能的规模化项目进展
- [ ] 氢能在工业脱碳（炼钢/化工）的规模化应用案例

## 公司与项目

- [ ] 宁德时代：钠电量产进展、凝聚态电池装车、海外大单
- [ ] 比亚迪：二代刀片电池装车、储能出货增长
- [ ] 阳光电源：海外大单节奏
- [ ] 通威：成都金堂/邛崃储能项目并网进展、源网荷储一体化推进
- [ ] 兴储世纪：钠电订单和量产能力变化
- [ ] 川发兴能：钒液流电池电解液技术突破

## 使用方式

- 不需要每条都每周更新。建议每月快速扫一遍，每季度做一次判断更新
- 如果某个维度出现显著变化（如钠电成本突然大幅下降、储能政策超预期），优先更新对应主文档
- 这份清单与具身智能的观察清单有交叉点（如电力巡检机器人），可以联动更新
