# 10-行业总览

## 行业定义

电力/能源/电池赛道涵盖三个紧密关联的方向：

- **电力侧：** 发电（光伏、风电、核电、氢能）、输电、配电、电力市场化交易
- **能源侧：** 新能源开发、能源互联网、综合智慧能源服务、源网荷储一体化
- **电池侧：** 锂电、钠电、固态电池、液流电池、储能系统

三者的交汇点是**储能**——它既是电力系统的"调节器"，也是电池产业的最大增量市场。

## 当前阶段判断

这个赛道已经过了"概念炒作期"，进入了**大规模装机和市场化验证**阶段。

标志性信号：
- 风光装机合计 18.98 亿千瓦，首次超过火电，占总装机 47.9%（2026年Q1）
- 新型储能累计装机 144.7GW，占全球 51.9%，连续四年全球第一
- 储能从"强制配储"的政策驱动转向"容量电价+现货市场"的市场化驱动
- 锂电池出货占全球 94.4%，钠电量产元年启动，固态电池阶梯式商业化共识达成
- "算电协同"首次写入政府工作报告，储能列入国家六大新兴支柱产业

**这不是一个"已经饱和"的赛道，而是一个从爆发式增长进入增速换挡、但绝对增量依然可观的阶段。**

## 行业规模

| 指标 | 数据 |
|------|------|
| 可再生能源总装机 | 23.95 亿千瓦（占总装机 60.4%） |

| 2026年储能新增预测 | 约 265GWh（同比+63%） |
| 新型储能产业链产值 | 超 1.5 万亿元 |
| 2025-2027年投资计划 | 超 2500 亿元 |
| 全球储能电池出货 | 中国企业占 94.4%（614.7GWh） |

## 对用户意味着什么

1. **就业确定性高。** 万亿级产业、人才缺口明确，不像纯概念型赛道有踩空风险
2. **技术路线多元，入口多。** 材料/化工/电气/机械/软件都能找到适配方向
3. **成都本地有产业土壤。** 通威（全球电池片第一）、清华四川能源互联网研究院、兴储世纪（钠电）、川发兴能（液流）、多个储能电站在建
4. **与具身智能存在交叉。** 电力巡检机器人、储能智慧运维、AI+电网调度等方向需要跨领域能力
