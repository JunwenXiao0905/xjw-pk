# 四川大学空天科学与工程学院

## 学院定位
- 独立招生单位代码：`621`
- 更像：
  - `航天器 / 飞行器`
  - `控制与信息`
  - `飞行器设计`
  - `机器人卫星 / 七院七部协同`
- 如果以后想把 `航天器 + 控制 + 空天系统` 串起来，川大是成都最值得单独盯的一条线。

## 公开合作

### 七院七部机器人卫星实验室
- 川大和 `航天科技七院七部` 联合申报的 `机器人卫星实验室`，获批为 `四川省首批国防科技重点实验室`。
- 这说明川大空天不是纯校内教学口径，而是已经接到真实军工院所合作平台。

### 川大空天的进入方式
- 真正进入 `机器人卫星实验室`，更看：
  - `导师`
  - `课题`
  - `联合培养`
- 不是考上空天学院就自动进入。

## 更适合什么背景

### 更适合 `082500` 或 `085503`
- 想走：
  - 控制
  - 仿真
  - 系统工程
  - 机器人卫星
  - 空天信息与控制

### 更适合 `085504`
- 想走：
  - 结构
  - 机构
  - 机械设计
  - 机电与飞行器工程

## 对我当前最有用的判断
- 如果目标是 `机器人卫星实验室`，川大是成都最直接的学校入口。
- 如果背景更偏 `软件 / GIS / 信息`，通常比起 `085504`，更值得优先看：
  - `082500`
  - `085503`
