# 成都理工大学空天信息交叉入口

## 先说定位
- 成都理工大学是成都的 `双一流高校`，但它不是标准的 `航空航天学院` 路线。
- 更适合把它放在：
  - `空间科学`
  - `对地观测`
  - `遥感`
  - `测绘`
  - `空间信息处理`
  这条交叉入口里看。

## 为什么它和航空航天有关
- 学校本科层面明确有 `空间科学与技术` 专业。
- 官方培养方案直接写到：
  - 面向 `空间探测`
  - `航空航天`
  - `对地观测与导航系统`
  - `空间信息处理`
- 所以这条线不是传统飞行器设计，而是更接近 `空天信息`。

## 当前更该看的研究生入口

### `081600 测绘科学与技术`
- 研究方向：
  - `大地测量学与测量工程`
  - `摄影测量与遥感`
  - `地图制图学与地理信息工程`
- 初试：
  - `101 思想政治理论`
  - `201 英语（一）`
  - `301 数学（一）`
  - `802 测绘学概论`
- 复试：
  - `3S技术及应用` 或 `大地测量学基础`
- 同等学力加试：
  - `遥感图像处理`
  - `地理信息系统工程设计`

### `085704 测绘工程`
- 研究方向：
  - `现代测量技术`
  - `遥感技术与应用`
  - `地理信息工程`
- 初试：
  - `101 思想政治理论`
  - `204 英语（二）`
  - `302 数学（二）`
  - `802 测绘学概论`
- 复试：
  - `3S技术及应用` 或 `大地测量学基础`
- 同等学力加试：
  - `遥感图像处理`
  - `地理信息系统工程设计`

## 为什么不和川大 / 成电 / 西交放在同一层比较
- 当前没有查到它有独立的 `航空航天学院` 招生路径。
- 它更强的是：
  - 地学
  - 遥感
  - 测绘
  - 空间信息
- 所以如果目标是：
  - `卫星遥感`
  - `对地观测`
  - `空间信息处理`
  - `GIS 与空天融合`
  它很值得看。
- 如果目标是：
  - `航天器`
  - `飞行器控制`
  - `卫星互联网主链`
  前三所会更直接。

## 校企合作更像什么
- 更偏 `空间信息产业链`，不是典型的航天主机厂链。
- 公开材料里能看到的合作对象包括：
  - `四川省遥感院`
  - `Esri中国`
  - `中地数码`
  - `超图`
  - `四川省测绘局`
- 这说明它更适合作为：
  - `遥感 / GIS / 测绘 -> 空天信息` 的转向入口。

## 对我当前最有用的判断
- 如果想保留 `GIS` 背景优势，同时又想和航空航天挂钩，成都理工比“硬跨纯飞行器”更顺手。
- 但如果目标已经明确是：
  - `机器人卫星`
  - `中国星网`
  - `七院七部`
  那就不要把成都理工当第一入口。
