# 中国商业航天公司

## 先分清三类主体
- `国家级平台 / 央国企商业化平台`
  - 中国星网
  - 中国卫通
  - 航天行云
  - 虹云 / 卫星移动通信相关平台
- `民营 / 混合所有制商业航天公司`
  - 商业火箭
  - 商业卫星整星
  - 商业测运控
- `星地应用与数据平台`
  - 卫星互联网应用
  - 遥感数据服务
  - AI 卫星 / 天基计算

## 火箭发射公司

### 蓝箭航天
- 关键词：
  - `液氧甲烷`
  - `中大型运载火箭`
  - `发射服务`
- 更像：
  - 商业火箭里偏 `液体火箭主线` 的头部公司。

### 星河动力
- 关键词：
  - `谷神星`
  - `中小型商业发射`
- 更像：
  - 商业火箭里偏 `中小运力、持续执行任务` 的重要玩家。

### 中科宇航
- 关键词：
  - `中科院孵化`
  - `中大型商业运载火箭`
- 更像：
  - `国家科研体系孵化出来的商业火箭公司`，不是纯互联网式创业公司。

### 东方空间
- 关键词：
  - `引力系列`
  - `太空运输`
- 更像：
  - 近两年非常值得盯的大运力商业火箭玩家。

### 天兵科技
- 关键词：
  - `液体火箭`
  - `可回收`
- 更像：
  - 商业液体火箭路线的重要竞争者。

## 卫星整星与星座公司

### 银河航天
- 关键词：
  - `低轨宽带通信`
  - `卫星互联网`
  - `小蜘蛛网`
- 更像：
  - 国内商业卫星互联网最典型的代表公司之一。
- 如果以后重点看 `卫星通信 / 卫星互联网`，这家必须长期跟踪。

### 国星宇航
- 关键词：
  - `成都`
  - `AI卫星`
  - `智能卫星互联网`
- 更像：
  - 成都本地最值得重点盯的商业航天公司之一。
- 如果以后想把 `GIS / 遥感 / 空天信息 / AI` 和商业航天接起来，这家优先级很高。

### 微纳星空
- 关键词：
  - `商业卫星研发制造`
  - `星地一体化交付`
- 更像：
  - `整星制造 + 一站式交付` 的代表性公司。

## 测运控与地面基础设施

### 航天驭星
- 关键词：
  - `测运控`
  - `地面站`
  - `在轨管理`
- 更像：
  - 商业航天里的 `基础设施服务商`。
- 它不是最容易被看见的“明星火箭公司”，但离真实业务闭环很近。

## 央国企商业化平台

### 中国星网
- 关键词：
  - `国家级卫星互联网平台`
  - `低轨星座`
- 更像：
  - 中国卫星互联网的主组织平台，不是普通创业公司。

### 中国卫通
- 关键词：
  - `高轨通信广播卫星`
  - `运营`
- 更像：
  - 商业化程度很高的央企卫星运营平台。

### 航天行云
- 关键词：
  - `行云工程`
  - `天基物联网`
- 更像：
  - 航天科工体系里的商业航天网络平台。

### 虹云相关平台
- 关键词：
  - `宽带星座`
  - `卫星互联网`
- 更像：
  - 航天科技体系里的商业卫星互联网尝试。

## 成都最值得单独盯的点
- `国星宇航`
- `电子科技大学卫星产业技术研究院 + 国星宇航`
- `四川大学空天 + 七院七部`
- `七院体系下可能外溢出来的航天制造、动力、配套公司`

## 怎么判断一家公司值不值得长期跟踪

### 火箭公司
- 看：
  - 是否已经稳定入轨
  - 发射频率是否连续
  - 是 `固体` 还是 `液体`
  - 是否有自己的总装、试验、发射组织能力

### 卫星整星公司
- 看：
  - 是不是只会做样星
  - 有没有真实在轨星座
  - 有没有 `终端 + 网络 + 应用` 的闭环

### 应用公司
- 看：
  - 政企客户是不是长期付费
  - 有没有跨区域、海外落地
  - 是卖 `数据`、`平台` 还是 `真实服务`

## 对我当前最有用的优先级
- 想看 `卫星互联网`：
  - 先看 `银河航天`
  - 再看 `中国星网`
  - 再看 `中国卫通`
- 想看 `成都本地机会`：
  - 先看 `国星宇航`
- 想看 `工程化和基础设施`：
  - 先看 `航天驭星`
- 想看 `火箭产业链`：
  - 先看 `蓝箭航天`
  - 再看 `中科宇航`
  - 再看 `星河动力 / 东方空间 / 天兵科技`
