# 电子科技大学航空航天学院

## 学院定位
- 学院名称：`航空航天学院（空天科学技术研究院）`
- 官方口径成立时间：`2006年7月`
- 学科特色主线：
  - `飞行器 + 电子信息`
  - `飞行器 + 智能技术`
  - `空天信息工程`
  - `空天控制工程`
- 如果以后重点看：
  - `卫星互联网`
  - `空天信息`
  - `控制`
  - `智能飞行器`
  - `AI + 航天`
  这所学校在成都最有辨识度。

## 公开合作

### 中国星网联合培养
- 电子科大和 `中国星网` 已开展联合培养博士专项。
- 公开通知里，航空航天学院可承接：
  - `航空宇航科学与技术`
  - `电子信息`
- 这说明成电已经不是“和行业有松散联系”，而是进了 `卫星互联网央企平台` 的联合培养链条。

### 卫星产业技术研究院 + 国星宇航
- 电子科大卫星产业技术研究院与 `国星宇航` 联合主办过卫星互联网产品发布活动。
- 这条线更接近：
  - `商业卫星互联网`
  - `AI卫星`
  - `成都本地产业落地`

## 更适合什么背景
- `082500`
  - 适合 `力学 + 控制` 或 `信息 + 控制` 两类人
- `081100`
  - 适合控制底子更强的人
- `086100`
  - 适合空管、空天运输、系统工程
- `089901`
  - 适合信号、控制、通信、空天地融合

## 对我当前最有用的判断
- 如果以后重点想往 `卫星互联网 / 空天信息 / 中国星网 / 国星宇航` 靠，成电在成都优先级最高。
- 如果背景偏 `GIS / 遥感 / 信息 / 控制`，成电比传统航空院校更顺手。
