# 成都双一流高校与航空航天

## 先看结论
- `主入口`
  - `四川大学`
  - `电子科技大学`
  - `西南交通大学`
- `交叉入口`
  - `成都理工大学`

## 为什么只把前三所放在主入口
- `四川大学` 有独立的 `空天科学与工程学院`，而且已经和七院七部形成联合实验室。
- `电子科技大学` 有独立的 `航空航天学院`，而且和 `中国星网`、`卫星互联网`、`空天信息` 的连接最强。
- `西南交通大学` 有独立的 `力学与航空航天学院`，适合作为 `力学 / 结构 / 飞行器工程` 入口。
- `成都理工大学` 是双一流，但更像 `空间信息 / 遥感 / 对地观测 / 测绘` 的交叉入口，不是标准的航空航天学院路线。

## 分数直觉
- 如果只看 `航空宇航科学与技术` 这条学硕主线：
  - `西南交大` 当前门槛最低
  - `川大` 居中
  - `电子科大` 略高，而且学校整体工科筛选更强
- 如果你更看重 `控制 / 空天信息 / 卫星互联网`，不能只看分数：
  - `电子科大` 的平台连接和方向辨识度最高
- 如果你更看重 `航天器 / 机器人卫星 / 七院七部`：
  - `川大` 更直接

## 怎么选学校

### 想走航天器、卫星、机器人卫星
- 优先看：
  - [[03a-四川大学空天科学与工程学院]]

### 想走空天信息、卫星互联网、空天控制、AI
- 优先看：
  - [[03b-电子科技大学航空航天学院]]

### 想走力学、结构、飞行器设计、工程底座
- 优先看：
  - [[03c-西南交通大学力学与航空航天学院]]

### 想保留 GIS / 遥感 / 对地观测优势
- 优先看：
  - [[03d-成都理工大学空天信息交叉入口]]

## 对我当前最有用的判断
- `川大`：更像 `航天器 / 控制 / 七院七部协同`
- `成电`：更像 `空天信息 / 卫星互联网 / 中国星网 / 国星宇航`
- `西交`：更像 `力学 / 结构 / 飞行器工程 / 七院就业链`
- `成理`：更像 `遥感 / 测绘 / 空间科学 / 对地观测`
