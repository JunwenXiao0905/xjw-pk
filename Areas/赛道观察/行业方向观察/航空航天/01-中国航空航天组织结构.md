# 中国航空航天组织结构

## 先记住四层
- `政府管理层`
  - `国务院国资委`：管中央企业名单和出资关系。
  - `工信部 / 国防科工局 / 国家航天局`：更偏航天行业管理、国防科技工业管理、民用航天管理。
- `航空制造层`
  - `中国航空工业集团（AVIC）`：军机、直升机、机载系统、航空工业研究所体系。
  - `中国商飞（COMAC）`：大飞机和支线客机的整机主机厂体系。
  - `中国航发（AECC）`：航空发动机和传动系统。
- `航天科研生产层`
  - `中国航天科技集团（CASC）`：火箭、卫星、飞船、深空探测器、空间站的主力体系。
  - `中国航天科工集团（CASIC）`：防务、飞航、快舟、行云等，商业航天也有布局。
- `卫星互联网与运营层`
  - `中国星网`：国家级卫星互联网组织平台。
  - `中国卫通`：通信广播卫星运营国家队。
  - `中国电科网通体系`：芯片、模组、接入网、核心网、测运控。
  - `中国电信卫星公司 / 中国移动 / 中国联通`：商用入口和运营能力。

## 航空主链

### 中国航空工业集团
- 更像 `军机 + 直升机 + 机载系统 + 大型航空工业体系`。
- 成都相关节点通常会想到：
  - `成飞`
  - `611所`
- 如果以后看航空岗、航空制造、航空结构设计，这一条是主干。

### 中国商飞
- 更像 `中国民机整机主机厂`。
- 主要看：
  - `C919`
  - `ARJ21`
  - 干线 / 支线民机产业链
- 如果以后看民机整机、民机适航、航电、总装制造，这一条是主干。

### 中国航发
- 更像 `航空发动机国家队`。
- 如果以后看发动机、热端、燃烧、传动、商发，这一条必须单独看。

## 航天主链

### 中国航天科技集团
- 航天主链的核心。
- 官方口径：辖 `1家体系院、8家研究院、12家专业公司、6家直属单位`。
- 更应该记住的是几类单位：
  - `一院`：火箭
  - `五院`：卫星、飞船、探测器
  - `七院`：四川航天工业联合体
  - `八院`：上海航天
  - `九院`：航天电子

### 五院
- 五院就是 `中国空间技术研究院`。
- 更像 `航天器大院`，做卫星、飞船、深空探测器。
- 五院下面还要再拆：
  - `通信与导航卫星总体部`
  - `北京控制工程研究所`
  - `西安分院`
  - `制造公司 / 上市平台`

### 七院
- 七院就是 `四川航天技术研究院`。
- 更像 `成都本地最重要的航天工业联合体之一`。
- 里面既有院所，也有工厂、设计院、公司。
- 更偏：
  - 制造
  - 动力
  - 火工
  - 机电液
  - 配套协作

### 中国航天科工集团
- 不是航天科技的下级，是并列央企。
- 更偏：
  - 防务
  - 飞航
  - 导弹体系
  - 快舟
  - 行云等商业航天项目

## 卫星通信与卫星互联网

### 中国星网
- 国家级卫星互联网平台。
- 更像 `国网星座 / 卫星互联网建设运营的总平台`。
- 和高校合作已经明显加速，电子科大就是公开入口之一。

### 中国卫通
- 航天科技集团下面的专业子公司。
- 更像 `高轨通信卫星资源运营商`。
- 如果以后单独梳理卫星通信，这家要和五院一起看。

### 五院通导总体部 + 西安分院
- `通信与导航卫星总体部`：通导卫星总体抓总。
- `西安分院`：空间电子信息技术、通信载荷、星载天线、星间链路等。
- 这一条是 `造通信卫星` 的技术源头。

### 中国电科网通体系
- 更像 `地面和终端`。
- 重点不是“造卫星”，而是：
  - 芯片
  - 模组
  - 接入网
  - 核心网
  - 测运控

## 成都相关节点
- `四川航天技术研究院（七院）`
- `电子科技大学航空航天学院`
- `电子科技大学卫星产业技术研究院`
- `四川大学 + 七院七部机器人卫星实验室`
- `国星宇航`
- `西南交通大学力学与航空航天学院`
- `成都理工大学空间科学与技术 / 测绘 / 遥感`

## 对我当前最有用的拆法
- 想看 `航天器 / 机器人卫星 / 航天器控制`：
  - 先看 `五院`
  - 再看 `川大空天`
- 想看 `卫星互联网 / 空天信息 / 卫星通信`：
  - 先看 `中国星网 / 中国卫通 / 五院通导 / 中国电科`
  - 再看 `电子科大`
- 想看 `成都本地航天工业就业链`：
  - 先看 `七院`
  - 再看 `西交力航`
