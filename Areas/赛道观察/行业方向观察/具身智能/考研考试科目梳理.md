# 具身智能相关考研考试科目梳理

## 先说结论
- 你如果想通过考研进入 `具身智能 / 机器人 / 控制 / 感知 / 交叉智能系统`，大多数专业的初试都是 `4 门`。
- 最常见结构是：
  - `101 思想政治理论`
  - `英语（一）` 或 `英语（二）`
  - `数学（一）` 或 `数学（二）`
  - `1 门学校自命题专业课`
- 真正拉开差距的通常不是政治，而是：
  - 你考的是 `英语一` 还是 `英语二`
  - 你考的是 `数学一` 还是 `数学二`
  - 第四门专业课是 `自动控制原理 / 机械原理 / 机械设计 / 电路分析 / 信号与系统 / 数字图像处理` 里的哪一门

## 先把这些代码看懂

### 公共课代码
- `101`：思想政治理论
- `201`：英语（一）
- `204`：英语（二）
- `301`：数学（一）
- `302`：数学（二）
- `306`：临床医学综合能力（西医）
- `312`：心理学专业基础
- `349`：药学综合
- `408`：计算机学科专业基础

### 对你最重要的区别
- `学硕` 更常见：
  - `英语一`
  - `数学一`
- `专硕` 更常见：
  - `英语二`
  - `数学二`
- 但不是绝对规则。比如：
  - 电子科大的 `085500 机械` 专硕，依然考 `英语一 + 数学一`
  - 所以一定不能只看专业代码，还要看 `学校 + 学院 + 具体方向`

## 这些科目大概在考什么

### 自动控制原理
- 最典型的机器人/控制方向专业课之一。
- 常见内容：
  - 传递函数
  - 时域分析
  - 根轨迹
  - 频域分析
  - 稳定性判据
  - 校正
- 如果以后想走：
  - 控制
  - 运动控制
  - 机器人系统
  - 无人系统
  这门很核心。

### 机械原理 / 机械设计
- 更偏机械本体、机构、传动、设计基础。
- 常见内容：
  - 平面机构
  - 齿轮机构
  - 轮系
  - 凸轮
  - 机械传动
  - 轴、轴承、联接
- 如果以后更偏：
  - 机器人本体
  - 机械结构
  - 智能制造装备
  - 机电设计
  这类科目更常见。

### 电路分析
- 更偏电气、电子、轨交电气化、控制底层。
- 常见内容：
  - 电路定律
  - 暂态分析
  - 正弦稳态
  - 频域分析
  - 二端口网络
- 适合：
  - 电气
  - 轨交控制
  - 电机与驱动
  - 工业控制底层

### 信号与系统
- 更偏感知、控制、信息处理。
- 常见内容：
  - 连续/离散信号
  - 卷积
  - 傅里叶变换
  - 拉普拉斯变换
  - Z 变换
  - 系统响应
- 适合：
  - 感知
  - 导航
  - 信号处理
  - 控制交叉方向

### 数字图像处理
- 更偏视觉、医学图像、感知。
- 常见内容：
  - 图像增强
  - 图像分割
  - 频域处理
  - 特征提取
  - 图像变换
- 如果你以后想走：
  - 医疗机器人
  - 视觉感知
  - 图像分析
  - 生物医学工程
  这门就很关键。

## 一个最实用的选校方法

### 如果你不想一上来就选错
- 想走 `机器人本体 / 智能制造`：
  - 优先选 `机械原理 / 机械设计 / 理论力学` 路线
- 想走 `控制 / 运动控制 / 具身系统大脑`：
  - 优先选 `自动控制原理 / 信号与系统 / 电路分析` 路线
- 想走 `医疗感知 / 视觉 / 医工交叉`：
  - 优先选 `数字图像处理 / 理化基础 / 生物医学工程` 路线

## 对你当前最重要的提醒
- 同样叫“机械”或“控制工程”，不同学校的考试科目差别很大。
- 甚至同一学校、不同学院、同一专业代码，科目也可能不同。
- 所以真正报考前，一定要锁定到这一级：
  - `学校`
  - `学院`
  - `专业代码`
  - `研究方向`

## 我对成都这几所学校的直观难度判断

### 偏“控制 / 系统 / 算法”难度较高
- `电子科技大学自动化`
- `四川大学控制 / 智能科学与技术`
- 原因：
  - `英一 + 数一 + 自动控制原理`
  - 对数学、控制基础要求更高

### 偏“机械 / 智能制造”更典型
- `西南交通大学机械`
- `四川大学机械`
- `电子科技大学机械与电气`
- 原因：
  - 更强调机械基础和机构 / 力学 / 设计底子

### 偏“交叉应用”
- `电子科技大学生物医学工程`
- `四川大学生物医学工程`
- `四川大学空天工程`
- 原因：
  - 技术路径更有辨识度
  - 但要看你能不能接受专业课更偏图像、理化、空天控制
