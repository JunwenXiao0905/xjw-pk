# 21-成都与本地机会

## 整体判断

成都的具身智能机会不在岗位数量（不如北上深），而在**场景结合更紧密、研究平台更多、闭环路径更清晰**。本地优势集中在三条线：轨交巡检、电力特种、医疗康复。

### 交叉入口学校

- **成都中医药大学 智能医学学院：** 医学 + AI + 智能装备 + 银发服务交叉入口。不是传统机器人主入口，但在医疗机器人/智慧康复/银发经济路线上有独特辨识度
- **西南财经大学：** 不适合做技术主入口，但适合做机器人产业研究、商业化、养老金融与投研

## 成都本地企业与研究平台

### 人形/前沿侧
- **成都人形机器人创新中心** — 招大模型算法、SLAM 导航、规划控制、机器人软件。学历偏硕博及优秀本科。这是成都本地最接近通用具身智能前台的机构

### 感知/研究侧
- **天府绛溪实验室** — SLAM 算法工程师（激光/VSLAM 方向）。偏硕博优先，要求机器人感知方案设计与实现、英文文献阅读。偏研究型岗位

### 工业/工程侧
- **成都卡诺普机器人** — 工业机器人老牌企业，从工业机器人向具身智能延展。适合控制器研发、应用工程、系统集成、运动控制
- **中国兵器装备集团自动化研究所（绵阳）** — 军工机器人运动控制算法。壁垒高，稳定性强

### 服务/场景侧
- **成都越凡创新** — 全自主服务机器人，配送/零售/社区服务。偏移动机器人算法、调度系统、场景产品、机器人运营

## 成都本地岗位的共同要求

- **学历：** 核心研发岗偏硕士及以上；优秀本科通常需要在项目、竞赛、论文或真机经验上很强
- **共性技能：** Python / C++ / Linux / ROS-ROS2 / SLAM / 规划与控制 / 多传感器融合 / 模型训练与部署 / 真机调试
- **成都特别有辨识度的能力：** SLAM/导航、机器人软件平台、工业/服务/巡检场景适配、特种场景机器人

## 成都的 9 大交叉应用方向

### 第一梯队（学校-平台-场景支撑明确）

1. **轨道交通 + 机器人/巡检** — 西南交大核心场景。高铁箱梁智能巡检、交通装备控制、轨交运维。这是成都最强、最现实、最容易落地的交叉方向
2. **电力/核电 + 特种机器人** — 川大电气 + 上海电气核电场景。电力巡检、核电特种作业、智能装备状态感知。常被低估但落地价值最高
3. **医疗/康复 + 智能医学** — 川大+成电+成中医+华西。康复机器人、手术辅助、医疗物流、智能诊疗。成都医疗资源+工科学校的组合全国少见

### 第二梯队（技术上贴近但更依赖行业周期）

4. **航空航天/低空 + 感知控制** — 成电航空航天学院、绛溪实验室。智能飞行器、空天信息控制、无人系统感知导航
5. **工业制造 + 具身执行** — 卡诺普、成电机电学院。柔性装配、协作机器人、产线自主决策
6. **社区服务/配送 + 移动机器人** — 越凡创新。室内外配送、社区服务、商业零售自动化

### 第三梯队（想象空间大但付费模式待验证）

7. **文旅 + 机器人** — 成都人形创新中心。文旅导览、场馆互动、城市展示
8. **银发经济/养老 + 服务机器人** — 成中医 + 成电生医。陪伴、康复训练、跌倒检测、慢病管理
9. **应急/消防/特种安防** — 川大电气。危险环境巡检、应急搜救、消防辅助

## 对用户的意义

### 如果在成都读研
- 冲研发主线：成电 > 川大 > 西交（控制/算法/感知/SLAM 方向）
- 走场景结合：西交 > 川大 > 成中医（轨交/电力/医疗方向）
- 性价比路线：成都理工 > 西华 > 西南石油 > 成信大（就业导向、工程能力积累）

### 如果在成都就业
- 不要只盯人形创业公司
- 同步看工业机器人（卡诺普）、服务机器人（越凡）、研究平台（绛溪实验室、人形创新中心）、军工（兵装研究所）
- 成都本地最有壁垒的岗位组合：SLAM + 控制 + 行业场景（轨交/电力/医疗）
