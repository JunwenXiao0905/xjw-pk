# 41-观察清单

持续跟踪具身智能赛道变化的信号清单。每一项都不是一次性的，而是需要定期回看的"触角"。

## 政策

- [ ] 北京/上海/成都三个创新中心的新动作（平台开放、合作签约、训练场进展）
- [ ] 国家层面是否出台具身智能产业专项政策
- [ ] 军采和特种行业对四足/巡检/消防机器人的采购是否持续扩大
- [ ] 地方层面（四川省/成都市）是否出台机器人产业专项支持

## 招聘

- [ ] 成都人形机器人创新中心的岗位变化（数量、方向、学历要求）—— 这是成都本地最具信号意义的招聘窗口
- [ ] 天府绛溪实验室的 SLAM/感知岗位是否持续放出
- [ ] 宇树、智元、银河通用等独角兽的招聘量和方向变化
- [ ] 头部公司招聘是从"纯算法"转向"软硬结合/真机部署"，还是反方向
- [ ] 成都本地 SLAM/控制/感知岗位是否持续增加

## 量产与订单

- [ ] 头部人形机器人公司是否在工厂场景实现百台以上交付
- [ ] 宇树/云深处的四足出货量和行业应用案例
- [ ] 电网、铁路、核电领域的巡检机器人公开招投标
- [ ] 是否有新的工业场景（非展陈/非实验室）进入常态化运行

## 场景落地

- [ ] 轨交巡检（西交方向）：是否有新的试点或交付案例
- [ ] 电力/核电特种（川大方向）：是否有新的项目或合作
- [ ] 医疗康复（成电/成中医方向）：康复机器人的临床或审批进展
- [ ] 社区服务（越凡方向）：越凡创新是否有新场景或大客户
- [ ] 工业制造（卡诺普方向）：卡诺普的具身智能产品化进展

## 学校与实验室

- [ ] 成电、川大、西交是否新增机器人/具身智能相关专业或方向
- [ ] 成都高校与企业的新联合实验室或合作项目
- [ ] 各校复试线和考试科目是否调整
- [ ] 天府绛溪实验室是否有新的招聘方向和项目

## 投资与市场

- [ ] 机器人/自动化主题 ETF 的规模变化
- [ ] 上游零部件公司（减速器、传感器）的业绩指引和订单情况
- [ ] 头部一级市场公司的融资轮次、估值变化和上市计划
- [ ] A 股机器人板块的估值水平是否脱离基本面（警惕纯概念炒作）
- [ ] 是否有新的成都本地机器人相关公司进入融资或资本市场视野

## 技术与学术

- [ ] VLA/VLM 路线是否在真实场景（非实验室）出现突破性进展
- [ ] Sim2Real 是否有新的有效方法降低真机部署成本
- [ ] 开源机器人平台（青龙、天工）的生态是否活跃
- [ ] 国内高校/企业在顶会（CoRL、ICRA、RSS）的具身智能论文数量和质量

## 使用方式

- 不需要每条都每周更新。建议每月快速扫一遍，每季度做一次判断更新
- 如果某个维度出现显著变化（如成都突然放出大量新岗位、某家头部公司交付突破），优先更新对应主文档
- 这份清单本身就是用来防止"看多了新闻但忘了盯关键信号"
