# 11-产业结构与价值链

## 概览

具身智能的产业链可以拆成四层：上游零部件、中游能力栈、下游本体形态、场景侧应用。每一层的能力要求、壁垒强度和商业化节奏都不同。

## 上游：核心零部件

| 环节 | 关键内容 | 壁垒判断 |
|------|---------|---------|
| 传感器 | 相机、IMU、激光雷达、力/力矩传感器、触觉传感器 | 硬件壁垒中等偏高，标定与融合是软壁垒 |
| 执行器 | 电机、减速器、丝杠、液压/气动 | 高端减速器和关节模组仍受制于工艺和量产一致性 |
| 控制器 | 嵌入式主控、实时控制器、驱控一体 | 实时性、稳定性、国产化替代是主线 |
| 芯片 | GPU、NPU、MCU、FPGA | 训练侧仍以 NVIDIA 为主，推理侧国产替代在加速 |
| 电池/能源 | 高密度电池、能量管理 | 直接影响续航和整机可用性 |

上游对用户的意义：如果走硬件或机电方向，减速器、关节模组、传感标定是成都周边（绵阳、德阳装备制造带）有产业基础的方向。

## 中游：能力栈

这是软件和算法背景的人离具身智能最近的一层：

| 能力层 | 做什么 | 技术关键词 |
|--------|--------|-----------|
| 仿真与数据 | 合成数据生成、策略预训练、场景构建 | Isaac Sim, MuJoCo, Gazebo, Sim2Real |
| 模型与算法 | 感知、推理、任务规划、人机交互 | VLA, VLM, Transformer, 多模态学习 |
| 感知与 SLAM | 环境理解、定位建图、多传感器融合 | ORB-SLAM, EKF/UKF, 图优化, 视觉惯导 |
| 规划与控制 | 轨迹生成、运动控制、全身控制 | MPC, LQR, NMPC, WBC, MoveIt, OMPL |
| 工程化与部署 | 模型压缩、真机调试、跨硬件适配 | TensorRT, ONNX, ROS/ROS2, Linux, C++ |

中游的瓶颈不在"哪个算法更准"，而在**仿真训出来的策略能不能在真机上稳定跑通**。这个从仿真到真机的迁移（Sim2Real gap）是整个行业当前最大的工程难点之一。

## 下游：本体形态

| 形态 | 代表方向 | 当前成熟度 |
|------|---------|-----------|
| 人形机器人 | 通用具身平台 | 早期验证，离规模化最近的是展陈和科研平台 |
| 四足/轮足 | 巡检、安防、应急、军采 | 已出现真实订单，商业化进度最快 |
| 机械臂 | 工业抓取、装配、协作 | 最成熟，但增量在"智能化"而非本体 |
| AMR/移动底盘 | 物流、配送、社区服务 | 场景明确，技术和商业都较成熟 |
| 特种机器人 | 消防、核电、水下、排爆 | 高壁垒、小批量、强定制，军采和特种需求真实 |

对用户的关键判断：**四足和特种机器人比人形更早兑现订单，但人形代表了长期天花板。** 如果优先考虑就业确定性，四足/轮足/AMR/工业机械臂更稳妥；如果看长期技术高度，人形值得持续跟踪但不建议 all in。

## 场景侧

按成熟度从高到低排列：

1. **巡检与特种作业** — 电力、轨交、消防、核电、军采。订单真实，更看工程可靠性和交付能力
2. **工业制造** — 柔性装配、搬运、协作。有产业土壤但增速取决于 ROI
3. **物流与仓储** — 分拣、搬运、配送。场景明确，技术门槛相对成熟
4. **医疗与康复** — 手术辅助、康复训练、医院物流。技术含量高，合规门槛也高
5. **商业服务与社区** — 配送、迎宾、零售。离付费近但离大额订单远
6. **文旅与展陈** — 品牌展示、互动体验。适合技术打磨和数据积累，不适合作为主要收入模型

## 价值链判断

- **价值最集中的环节：** 能力栈中游（模型/算法/SLAM/控制），这是差异化最明显的地方
- **壁垒最强的环节：** 上游高端零部件（减速器、关节模组）和中游 Sim2Real 工程能力
- **离钱最近的环节：** 场景侧的巡检、特种作业和工业制造
- **成都本地最有优势的环节：** 场景结合（轨交、电力、医疗）和中游工程化能力（SLAM/导航/控制）
