# 20-玩家图谱

本文记录具身智能赛道值得持续跟踪的机构。不是完整名单，而是"对用户判断有持续意义的玩家"。

## 国央企 / 国资平台

### 国家地方共建具身智能机器人创新中心（北京）
- **所在环节：** 平台型 / 生态组织者
- **强项：** 通用机器人平台"天工"、通用具身智能平台"慧思开物"，做母平台和测试验证
- **当前阶段：** 已与京东、优必选等合作做仓储物流、工厂分拣、特种作业试点
- **对用户的意义：** 国内最权威的行业风向标，它的招聘方向和技术选型代表了顶层需求

### 国家地方共建人形机器人创新中心（上海）
- **所在环节：** 平台型 / 生态组织者
- **强项：** 开源公版机"青龙"、训练场建设，定位"底座平台 + 生态组织者"
- **当前阶段：** 已发布公版机、建设训练场，上海电气已签约共建训练场
- **对用户的意义：** 和北京中心形成南北双核，两个中心的技术路线差异值得持续观察

### 成都人形机器人创新中心
- **所在环节：** 地方创新平台
- **强项：** 成都本地具身智能生态的本地抓手，偏开源平台、展示、实验场景、城市级创新生态
- **当前阶段：** 招聘大模型算法、SLAM 导航算法、规划控制算法、机器人软件开发工程师
- **对用户的意义：** 成都本地最接近"通用具身智能前台"的机构，是观察成都具身智能岗位变化的核心窗口

### 上海电气
- **所在环节：** 场景落地（核电等特种工业）
- **强项：** 工业装备制造底蕴 + 核电场景资源
- **当前阶段：** 已与上海国地中心签约共建训练场，往核电特种工业场景落地
- **对用户的意义：** 代表"传统工业巨头 + 具身智能"的落地路线

## 合资平台

### 上海发那科
- **所在环节：** 工业机器人 / 系统集成
- **强项：** 上海电气 + 发那科联合投资，工业机器人、自动化产线、智能制造
- **对用户的意义：** 代表中国机器人产业最成熟的落地土壤。从就业稳定性看，比纯概念型创业公司更扎实

### 安川首钢机器人
- **所在环节：** 工业机器人 / 系统集成
- **强项：** 首钢 + 安川电机合资老牌平台
- **对用户的意义：** 工程训练强度高，适合积累工业机器人基本盘

## 独角兽 / 高热创业公司

### 宇树科技
- **所在环节：** 四足 + 人形机器人本体
- **强项：** 四足机器人出货能力和真机工程能力强，已在胡润全球独角兽榜
- **对用户的意义：** 四足商业化的标杆，它的招聘方向和出货数据是行业真实需求的风向标

### 智元机器人
- **所在环节：** 人形机器人本体
- **强项：** 估值约 150 亿元（2025-03），量产节奏快、生态动作多
- **当前阶段：** 被多家媒体按"超级独角兽"讨论
- **对用户的意义：** 适合持续看招聘。它的岗位变化直接反映人形赛道的人才需求结构

### 银河通用
- **所在环节：** 操作机器人 / VLA
- **强项：** 抓取、操作、VLA，估值约 30 亿美元（2025-12）
- **对用户的意义：** 算法含量在国内属于非常值得跟踪的一档。如果关注"具身大脑"方向，这家的技术路线值得研究

### 傅利叶智能
- **所在环节：** 康复机器人 -> 通用人形
- **强项：** 康复机器人起家，向通用人形延展
- **对用户的意义：** "医疗康复 -> 通用机器人"的迁移路线有参考价值，尤其对成都医疗康复方向

### 云深处科技
- **所在环节：** 四足机器人 / 行业应用
- **强项：** 巡检、安防、应急等场景落地务实，已进入军采口径
- **对用户的意义：** 代表"先商业化还是先炫技"的前者路线。如果看重就业确定性，这类比纯人形更值得参考

## 成都本地重点公司

### 成都卡诺普机器人
- **所在环节：** 工业机器人 / 系统集成 -> 具身智能延展
- **强项：** 成都老牌机器人企业，控制器、系统集成、制造落地
- **对用户的意义：** 在成都先站稳机器人工程基本盘的核心选择，偏控制器研发、应用工程、系统集成

### 成都越凡创新
- **所在环节：** 服务机器人 / 配送 / 零售 / 社区
- **强项：** 全自主服务机器人，"从真实场景反向定义技术架构"，自研机器人操作系统
- **对用户的意义：** 不做人形但非常适合看"服务机器人 -> 具身智能"路线。偏移动机器人算法、调度系统、场景产品

## 成都本地研究平台

### 天府绛溪实验室
- **所在环节：** 感知与导航研究
- **强项：** 激光 SLAM、VSLAM、多传感器感知方案设计与实现
- **对用户的意义：** 成都本地 SLAM/感知方向研究型岗位的代表，对论文和高水平科研经历有要求

### 电子科技大学机器人研究中心
- **所在环节：** 高校研究平台
- **强项：** 外骨骼机器人、家用服务机器人、手术机器人视觉、社会机器人、3D 视觉
- **对用户的意义：** 成电是成都最像"具身智能大脑侧入口"的学校

### 中国兵器装备集团自动化研究所（绵阳）
- **所在环节：** 军工/特种机器人
- **强项：** 机器人运动控制算法
- **对用户的意义：** 说明军工/特种机器人平台在成都-绵阳持续布局，岗位壁垒高但稳定性强

## 军采 / 特种场景线索

- 军队采购网已出现四足机器狗 M20 Pro（云深处）的直接采购
- 消防灭火机器人采购落地（山东国兴智能）
- 这类需求更看重：加密通信、可靠性、国产化、自主运维、极端工况适应
