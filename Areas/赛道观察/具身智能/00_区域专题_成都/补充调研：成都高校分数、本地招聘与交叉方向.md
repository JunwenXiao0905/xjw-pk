## 口径说明
- 本文是对 [行业线索.md](D:/aaa_xjw/doc/xjw-pk/Areas/赛道观察/行业方向观察/具身智能/行业线索.md) 的补充。
- “近三年分数”按当前时间口径，统一看 `2024 / 2025 / 2026` 三个招生周期。
- 分数优先使用学校或学院官网公布的 `进入复试初试成绩要求`，它是复试门槛，不等于最终录取线。
- “成都双一流及以上学校”分成两类看：
  - `主入口`：能直接通往机器人、控制、机械、感知、智能系统
  - `交叉入口`：能通往医疗、银发、产业研究等具身智能应用侧

## 成都双一流及以上学校的近三年分数

### 先看结论
- 如果目标是 `机器人算法 / 控制 / 机械 / 感知 / 具身系统`，成都最值得重点看的主入口仍然是：
  - `四川大学`
  - `电子科技大学`
  - `西南交通大学`
- `成都中医药大学` 有明确的 `智能医学学院` 和 `中医药人工智能` 交叉方向，但它更适合 `医疗 + 银发 + 智慧健康` 路线，不是传统机器人技术主入口。
- `西南财经大学` 在成都双一流里也很重要，但它更适合做 `产业研究、数字经济、养老金融、机器人商业化与管理`，不适合当作具身智能技术路线的主要读研入口。

### 读法
- 川大的一个特点是：`机械 + 电气 + 控制 + 医学 + 交叉学科` 都能和具身智能发生连接。
- `2024 -> 2025 -> 2026` 的变化说明：
  - `0855 机械` 从 `305` 升到 `350` 后维持高位，说明竞争强度明显提升。
  - `0854 电子信息` 从 `320` 提到 `360`，比机械更陡，说明智能系统和软件侧热度更高。
  - `14 交叉学科` 在 `2026` 回升到 `320`，说明交叉路线也不再轻松。

- 如果你是软件或算法背景，成电是成都最像“具身智能大脑侧入口”的学校。
- 如果你是机电背景，成电的 `机械与电气 + 自动化` 也很强，但比传统机械院校更强调 `系统、控制、智能化`。

- `085500 机械` 在 `2026` 冲到 `365`，说明热门度和筛选强度都在提升。
- 如果未来目标不是通用人形，而是 `巡检、检修、轨交运维、车体/设施检测`，西南交大在成都是非常强的路线。

## 交叉入口学校

## 成都中医药大学
- 不建议把成中医和 `川大 / 成电 / 西交` 放在同一张“机器人技术主入口”表里比较。
- 但如果看 `医疗机器人 / 智慧康复 / 银发经济 / 智能照护 / 中医药智能装备`，它反而是成都非常有特色的学校。
- 学校公开口径已经明确：
  - 有 `智能医学学院`
  - 有 `中医药人工智能` 博士、硕士学位点
  - 有 `中医药信息学` 科学硕士学位点
  - 本科层面有 `医学信息工程`、`智能医学工程`
- 更适合的理解是：
  - 成中医不是“机器人本体学校”
  - 但它是 `医学 + AI + 智能装备 + 银发服务` 的本地交叉入口

## 西南财经大学
- 西财更适合：
  - 机器人产业研究
  - 养老金融 / 养老产业
  - 数字经济
  - 机器人商业模式与运营
  - 供应链、服务网络、场景经济
- 如果你目标是 `技术研发岗`，西财不是主入口。
- 如果你未来想做：
  - 机器人产业研究员
  - 机器人商业化
  - 养老科技投资 / 行业分析
  - 具身智能赛道的投研和产业运营
  它反而是成都双一流里很有辨识度的一条路。

## 成都本地企业 / 研究所招聘情况

### 先看整体判断
- 成都本地目前公开可见的具身智能相关岗位，主要集中在三类：
  - `人形机器人大脑 / 机器人软件 / 规划控制`
  - `SLAM / 感知 / 导航 / 多传感器融合`
  - `工业机器人 / 服务机器人 / 场景运营系统`
- 相比北京、上海、深圳，成都的优势不是岗位数量最多，而是：
  - 场景结合更强
  - 研究所/实验室平台多
  - 工业、轨交、医疗、社区服务这些本地落地场景更容易形成闭环

## 1. 成都人形机器人创新中心
- 当前公开样本岗位：
  - `大模型算法工程师`
  - `SLAM 导航算法工程师`
  - `规划控制算法工程师`
  - `机器人软件开发工程师`
- 岗位特征：
  - 学历通常偏 `硕士、博士及优秀本科`
  - 技能偏 `VLM/LLM`、多模态数据构建、训练评测部署、`SLAM`、导航、路径规划、`MPC/LQR/NMPC`
  - 说明成都本地已经不只是招传统控制岗，已经开始明确招 `机器人大脑` 侧岗位
- 判断
  - 这是成都本地最接近“通用具身智能前台”的机构
  - 如果你想看成都本地最像北京人形中心/上海国地中心那种岗位，这里优先级最高

## 2. 天府绛溪实验室
- 当前公开样本岗位：
  - `SLAM 算法工程师（激光 SLAM 方向）`
  - `SLAM 算法工程师（VSLAM 方向）`
- 岗位特征：
  - 偏 `硕士或博士优先`
  - 要求三维激光、深度相机、`IMU`、`GPS` 等机器人感知方案设计与实现
  - 要求多传感器感知、视觉/激光/语义 `SLAM`、数据融合
  - 英文文献阅读能力被明确写进要求
- 判断
  - 它更像“感知与导航研究型岗位”
  - 对做 `SLAM / 机器人感知 / 视觉导航` 的人很友好
  - 也说明成都本地研究机构对 `具身智能底层能力` 的需求是真实存在的

## 3. 成都卡诺普机器人
- 公司定位：
  - 成都本地老牌机器人企业，强项在 `工业机器人`、控制器、系统集成和制造落地
  - 官网已经明确提到从 `工业机器人` 向 `具身智能` 延展
- 招聘倾向
  - 从企业形态看，它更适合：
    - `控制器研发`
    - `机器人应用工程`
    - `系统集成`
    - `机械 / 电气 / 运动控制`
  - 比起纯 `VLA/世界模型`，这里更偏工程与产业化
- 判断
  - 如果你想在成都先站稳机器人工程基本盘，卡诺普的价值非常高
  - 它更像“工业机器人底座”和“工程能力训练场”

## 4. 成都越凡创新
- 公司定位：
  - 全自主服务机器人研发与制造商，做配送、零售、社区服务、商用移动机器人
  - 官网强调 `从真实场景反向定义技术架构`、自研 `机器人操作系统`
- 招聘倾向
  - 从招聘简章与官网口径看，更适合：
    - `移动机器人算法`
    - `机器人软件`
    - `调度系统`
    - `场景产品`
    - `机器人运营`
- 判断
  - 越凡不是做人形的，但非常适合看 `服务机器人 -> 具身智能` 这条现实路线
  - 如果你更关心商业闭环，这家公司的“场景先行”思路很值得观察

## 成都本地岗位的共同要求
- 学历：
  - 核心研发岗普遍更偏 `硕士及以上`
  - 优秀本科通常只有在项目、竞赛、论文或真机经验很强时才更有机会
- 共性技能：
  - `Python`
  - `C++`
  - `Linux`
  - `ROS / ROS2`
  - `SLAM`
  - `规划与控制`
  - 多传感器融合
  - 模型训练与部署
  - 真机调试
- 成都本地特别有辨识度的能力：
  - `SLAM / 导航`
  - `机器人软件平台`
  - `工业 / 服务 / 巡检场景适配`
  - `特种场景机器人`

## 具身智能的交叉学科与应用方向

### 1. 航空航天 / 低空经济
- 本地学校 / 平台
  - `电子科技大学航空航天学院`
  - `天府绛溪实验室`
- 典型结合点
  - `智能飞行器系统设计`
  - `空天信息控制及空天智能制造`
  - 无人系统感知、导航与控制
  - 低空巡检、机场与空地协同机器人
- 需要的能力
  - `SLAM`
  - 感知融合
  - 实时控制
  - 空地协同系统
- 判断
  - 这条线和“纯人形机器人”不完全一样，但它和具身智能共享大量底层能力

### 2. 轨道交通
- 本地学校 / 平台
  - `西南交通大学`
- 典型结合点
  - 轨交设施巡检机器人
  - 高铁箱梁智能巡检
  - 交通装备与控制工程
  - 轨道交通电气化与信息技术
- 需要的能力
  - 机器视觉
  - 巡检机器人控制
  - 感知与故障识别
  - 设备健康监测
- 判断
  - 这是成都最强、最现实、最容易落地的交叉方向之一
  - 如果你不执着于“必须是通用人形”，这条路线反而很强

### 3. 医疗 / 康复 / 手术 / 智慧医院
- 本地学校 / 平台
  - `电子科技大学生命科学与技术学院 / 医学院`
  - `四川大学医学与电气交叉`
  - `成都中医药大学智能医学学院`
- 典型结合点
  - 康复机器人
  - 智能手术辅助
  - 医疗物流机器人
  - 智能诊疗设备
  - 医疗数据驱动的机器人辅助系统
- 需要的能力
  - `生物医学工程`
  - 感知与控制
  - 人机交互
  - 医疗合规与临床场景理解
- 判断
  - 成都的这条线不是靠单一机器人公司，而是靠 `学校 + 医疗资源 + 智能医学交叉`

### 4. 银发经济 / 老年经济
- 本地学校 / 平台
  - `成都中医药大学智能医学学院`
  - `电子科技大学生物医学工程 / 康复相关方向`
  - `西南财经大学` 的养老金融与产业研究视角
- 典型结合点
  - 陪伴机器人
  - 康复训练机器人
  - 居家照护机器人
  - 跌倒检测与智能监护
  - 慢病管理和服药辅助
- 需要的能力
  - 医工融合
  - 人机交互
  - 场景产品设计
  - 服务系统运营
- 判断
  - 这是成都未来非常值得盯的一条应用赛道
  - 技术难点没有人形本体那么“炫”，但离付费场景更近

### 5. 电力 / 核电 / 能源特种场景
- 本地学校 / 平台
  - `四川大学电气工程学院`
- 典型结合点
  - 电力巡检机器人
  - 核电特种作业机器人
  - 智能装备状态感知
  - 故障诊断与可靠性预测
- 需要的能力
  - 感知与控制
  - 设备健康评估
  - 特种环境机器人系统
  - 可靠性工程
- 判断
  - 这是成都最值得重视、但常被低估的一条线
  - 具身智能不一定先在消费级人形爆发，也可能先在 `电力 / 核电 / 高危环境` 里跑通

### 6. 工业制造 / 智能制造
- 本地学校 / 平台
  - `电子科技大学机械与电气工程学院`
  - `西南交通大学机械工程学院`
  - `成都卡诺普机器人`

  - 搬运与抓取
  - 协作机器人
  - 产线自主决策
  - 具身智能在制造单元的局部落地
- 判断
  - 这条线最能训练真正的工程能力
  - 未来如果国内具身智能先从工厂切入，成都本地是有产业土壤的

### 7. 商业服务 / 配送 / 社区场景
- 本地学校 / 平台
  - `成都越凡创新`

  - 迎宾导览
  - 社区服务
  - 商业零售自动化
- 判断
  - 这是“具身智能先形成订单”的现实路径之一
  - 虽然不一定最前沿，但非常接近真实商业闭环

### 8. 文旅 / 展陈 / 城市服务
- 本地学校 / 平台
  - `成都人形机器人创新中心`
- 典型结合点
  - 文旅机器人
  - 城市展示机器人
  - 场馆互动
  - 会务与政务服务
- 判断
  - 这类场景技术门槛不一定最高，但特别适合成都这种文旅和会展资源强的城市
  - 更适合做品牌展示、数据采集、交互打磨和场景验证

### 9. 应急 / 消防 / 特种安防
- 本地学校 / 平台

  - 危险环境巡检

## 成都最值得重点观察的交叉路线

### 第一梯队
- `轨道交通 + 机器人 / 巡检`
- `电力核电 + 特种机器人`
- `医疗康复 + 智能医学`

原因：
- 成都本地有明确学校、平台和场景支撑
- 不是停留在概念层面
- 更容易形成研究、实习、就业的连续路径

### 第二梯队
- `航空航天 / 低空 + 感知控制`
- `工业制造 + 具身执行`
- `社区服务 / 配送 + 移动机器人`

原因：
- 技术上很贴近具身智能
- 但具体爆发节奏更依赖企业项目和行业周期

### 第三梯队
- `文旅 + 机器人`
- `养老陪伴 + 居家服务机器人`

原因：
- 场景想象力大
- 但真正成熟的大规模付费模式还需要时间验证
