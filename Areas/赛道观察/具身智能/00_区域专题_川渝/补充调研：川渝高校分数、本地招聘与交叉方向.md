# 具身智能补充调研：川渝高校分数、本地招聘与交叉方向

## 口径说明
- 本文是对 [行业线索.md](D:/aaa_xjw/doc/xjw-pk/Areas/赛道观察/行业方向观察/具身智能/行业线索.md) 的补充。
- “近三年分数”按当前时间口径，统一看 `2024 / 2025 / 2026` 三个招生周期。
- 分数优先使用学校或学院官网公布的 `进入复试初试成绩要求`，它是复试门槛，不等于最终录取线。
- “川渝双一流及以上学校”分成两类看：
  - `主入口`：能直接通往机器人、控制、机械、感知、智能系统
  - `交叉入口`：能通往医疗、银发、产业研究等具身智能应用侧
- 成都、重庆两地的分数与招聘分别成节，便于对照。重庆院校工科专硕普遍考英二+数二（不像成电专硕考英一+数一）；`重庆大学` 为 34 所自划线院校，校线是最低门槛，各学院还会二次划线。

## 成都双一流及以上学校的近三年分数

### 先看结论
- 如果目标是 `机器人算法 / 控制 / 机械 / 感知 / 具身系统`，成都最值得重点看的主入口仍然是：
  - `四川大学`
  - `电子科技大学`
  - `西南交通大学`
- `成都中医药大学` 有明确的 `智能医学学院` 和 `中医药人工智能` 交叉方向，但它更适合 `医疗 + 银发 + 智慧健康` 路线，不是传统机器人技术主入口。
- `西南财经大学` 在成都双一流里也很重要，但它更适合做 `产业研究、数字经济、养老金融、机器人商业化与管理`，不适合当作具身智能技术路线的主要读研入口。

- 川大的一个特点是：`机械 + 电气 + 控制 + 医学 + 交叉学科` 都能和具身智能发生连接。
- `2024 -> 2025 -> 2026` 的变化说明：
  - `0855 机械` 从 `305` 升到 `350` 后维持高位，说明竞争强度明显提升。
  - `0854 电子信息` 从 `320` 提到 `360`，比机械更陡，说明智能系统和软件侧热度更高。
  - `14 交叉学科` 在 `2026` 回升到 `320`，说明交叉路线也不再轻松。

## 重庆主要学校的近三年分数

### 先看结论
- 如果目标是 `机器人算法 / 控制 / 机械 / 感知 / 具身系统`，重庆最值得重点看的主入口是：
  - `重庆大学`（985，嘉陵江实验室、机器人与智能系统研究所，是少数把"具身智能"写进研究所名字的高校）
  - `重庆邮电大学`（控制考 805 自动控制原理，电子信息底子好，性价比高于重大/成电）
- `西南大学`（211）在 `农业机器人 / 智能农业装备` 上辨识度最高，但没有 `081100 控制` / `080200 机械` 一级硕士点，具身智能只能落在农业工程学硕、电子信息/车辆/农机专硕。
- `重庆理工大学`、`重庆交通大学` 是重庆第二梯队的现实选择：前者与汽车产业深度绑定（智能网联/自动驾驶测试），后者有交通应用机器人 + 跨座式轨交的场景壁垒。
- 异地研究院（`哈工大重庆研究院`、`北理工重庆创新中心`）和 `国科大重庆学院 / 中科院重庆绿色智能技术研究院` 是重庆独有红利：在重庆培养、学位由 985 本部 / 国科大授予。

## 交叉入口学校

## 成都中医药大学
- 不建议把成中医和 `川大 / 成电 / 西交` 放在同一张“机器人技术主入口”表里比较。
- 但如果看 `医疗机器人 / 智慧康复 / 银发经济 / 智能照护 / 中医药智能装备`，它反而是成都非常有特色的学校。
- 学校公开口径已经明确：
  - 有 `智能医学学院`
  - 有 `中医药人工智能` 博士、硕士学位点
  - 有 `中医药信息学` 科学硕士学位点
  - 本科层面有 `医学信息工程`、`智能医学工程`
- 更适合的理解是：
  - 成中医不是“机器人本体学校”
  - 但它是 `医学 + AI + 智能装备 + 银发服务` 的本地交叉入口

## 西南财经大学
- 西财更适合：
  - 机器人产业研究
  - 养老金融 / 养老产业
  - 数字经济
  - 机器人商业模式与运营
  - 供应链、服务网络、场景经济
- 如果你目标是 `技术研发岗`，西财不是主入口。
- 如果你未来想做：
  - 机器人产业研究员
  - 机器人商业化
  - 养老科技投资 / 行业分析
  - 具身智能赛道的投研和产业运营
  它反而是成都双一流里很有辨识度的一条路。

## 成都本地企业 / 研究所招聘情况

### 先看整体判断
- 成都本地目前公开可见的具身智能相关岗位，主要集中在三类：
  - `人形机器人大脑 / 机器人软件 / 规划控制`
  - `SLAM / 感知 / 导航 / 多传感器融合`
  - `工业机器人 / 服务机器人 / 场景运营系统`
- 相比北京、上海、深圳，成都的优势不是岗位数量最多，而是：
  - 场景结合更强
  - 研究所/实验室平台多
  - 工业、轨交、医疗、社区服务这些本地落地场景更容易形成闭环

## 1. 成都人形机器人创新中心
- 当前公开样本岗位：
  - `大模型算法工程师`
  - `SLAM 导航算法工程师`
  - `规划控制算法工程师`
  - `机器人软件开发工程师`
- 岗位特征：
  - 学历通常偏 `硕士、博士及优秀本科`
  - 技能偏 `VLM/LLM`、多模态数据构建、训练评测部署、`SLAM`、导航、路径规划、`MPC/LQR/NMPC`
  - 说明成都本地已经不只是招传统控制岗，已经开始明确招 `机器人大脑` 侧岗位
- 判断
  - 这是成都本地最接近“通用具身智能前台”的机构
  - 如果你想看成都本地最像北京人形中心/上海国地中心那种岗位，这里优先级最高

## 2. 天府绛溪实验室
- 当前公开样本岗位：
  - `SLAM 算法工程师（激光 SLAM 方向）`
  - `SLAM 算法工程师（VSLAM 方向）`
- 岗位特征：
  - 偏 `硕士或博士优先`
  - 要求三维激光、深度相机、`IMU`、`GPS` 等机器人感知方案设计与实现
  - 要求多传感器感知、视觉/激光/语义 `SLAM`、数据融合
  - 英文文献阅读能力被明确写进要求
- 判断
  - 它更像“感知与导航研究型岗位”
  - 对做 `SLAM / 机器人感知 / 视觉导航` 的人很友好
  - 也说明成都本地研究机构对 `具身智能底层能力` 的需求是真实存在的

## 3. 成都卡诺普机器人
- 公司定位：
  - 成都本地老牌机器人企业，强项在 `工业机器人`、控制器、系统集成和制造落地
  - 官网已经明确提到从 `工业机器人` 向 `具身智能` 延展
- 招聘倾向
  - 从企业形态看，它更适合：
    - `控制器研发`
    - `机器人应用工程`
    - `系统集成`
    - `机械 / 电气 / 运动控制`
  - 比起纯 `VLA/世界模型`，这里更偏工程与产业化
- 判断
  - 如果你想在成都先站稳机器人工程基本盘，卡诺普的价值非常高
  - 它更像“工业机器人底座”和“工程能力训练场”

## 4. 成都越凡创新

## 川渝最值得重点观察的交叉路线

> 把成都原有梯队与重庆方向合并。一句话:**成都偏"人形 + 军工 + 医疗",重庆偏"自动驾驶 + 智能制造 + 特种作业"。**

### 第一梯队（川渝各有主力）
- `智能驾驶 + 智能制造（汽车产业链）`【重庆主干道，长安/赛力斯，30-50 万】
- `轨道交通 + 机器人 / 巡检`【成都：西南交大；重庆：重庆交大（交通应用机器人、跨座式轨交、桥隧检测）】
- `电力核电 + 特种机器人`【成都：川大电气】
- `医疗康复 + 智能医学`【成都：川大+成电+成中医+华西；重庆：金山科技（胶囊内镜/手术机器人）、山外山】

原因：本地有明确学校、平台和场景支撑，不是停留在概念，更容易形成研究、实习、就业的连续路径。

### 第二梯队（技术上贴近，更依赖行业周期）
- `工业机器人本体 + 核心控制器（国产替代）`【重庆：华数/智能机器人研究院/嘉陵江实验室关节丝杠；成都：卡诺普】
- `人形 / 四足机器人`【成都：人形中心（原研）；重庆：宇树西部总部（运营/数据/落地）+ 嘉陵江实验室（科研）】
- `航空航天 / 低空 + 感知控制`【成都：成电航空航天、绛溪；重庆：重大航空航天（智能飞行器/无人机）】
- `社区服务 / 配送 + 移动机器人`【成都：越凡】

原因：技术上很贴近具身智能，但具体爆发节奏更依赖企业项目和行业周期。

### 第三梯队（场景想象力大 / 政策推动，付费模式待验证）
- `特种 / 军工 / 无人系统 + 山地地下作业`【重庆独家场景：北理工重庆陆域无人系统、嘉陵江实验室"地下空间复杂环境智能作业机器人"揭榜项目；成都：绵阳 58 所（人形+军工本体）】
- `银发经济 / 养老 + 服务机器人`【成都：成中医+成电生医】
- `农业机器人 / 智能农业装备`【重庆：西南大学，西南地区农业机器人最强入口】
- `文旅 + 机器人 / 智能建造`【成都：人形中心文旅导览；重庆：智能建造（桥隧/山地建筑）】

原因：场景想象力大 / 政策推动，但真正成熟的大规模付费模式还需要时间验证。
