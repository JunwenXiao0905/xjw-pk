# 21-川渝与本地机会

## 整体判断

把视角从"成都"放大到"川渝",机会地图会明显不一样。两座城市在具身智能上的分工是互补的,不是重复的:

| 维度          | 成都                     | 重庆                         |
| ----------- | ---------------------- | -------------------------- |
| 产业禀赋        | 电子信息、轨交、医疗、航空航天        | 汽车制造(全国前列)、装备/兵工、电子信息、山地城市 |
| 具身智能的"前台"形态 | 人形机器人创新中心、感知研究平台       | 智能驾驶 + 智能制造(产业链最大雇主)       |
| 本地最强交叉场景    | 轨交巡检、电力核电特种、医疗康复       | 智能网联汽车、工业机器人本体、山地/地下特种     |
| 人形机器人原研度    | 偏原研/创新中心(成都人形中心、绵阳58所) | 偏应用/数据/孵化(宇树西部总部、嘉陵江实验室)   |
| 旗舰高校        | 电子科大、川大、西南交大           | 重庆大学(嘉陵江实验室)、西南大学、重邮       |

一句话:**成都的具身智能偏"人形 + 军工 + 医疗",重庆偏"自动驾驶 + 智能制造 + 特种作业"。** 两者的底层能力栈(SLAM/感知/规控/ROS/真机调试)高度互通,但"最大量、薪资最高的近似岗位"在重庆是**长安/赛力斯的智能驾驶**(年薪 30-50 万),在成都是**人形中心/绛溪实验室的研究型岗位**。

川渝共同的本地优势:场景结合更紧密、研究平台更多、闭环路径更清晰。比起北上深,岗位绝对数量少,但更容易做出"学校-平台-场景-就业"的连续路径。

## 本地企业与研究平台

### 成都

**人形/前沿侧**
- **成都人形机器人创新中心** — 招大模型算法、SLAM 导航、规划控制、机器人软件。学历偏硕博及优秀本科。成都本地最接近通用具身智能前台的机构

**感知/研究侧**
- **天府绛溪实验室** — SLAM 算法工程师(激光/VSLAM 方向)。偏硕博优先,偏研究型岗位

**工业/工程侧**
- **成都卡诺普机器人** — 工业机器人老牌,从工业机器人向具身智能延展。适合控制器研发、应用工程、系统集成、运动控制
- **中国兵器装备集团自动化研究所(绵阳)** — 西南自动化研究所,军工机器人运动控制算法。壁垒高,稳定性强

**服务/场景侧**
- **成都越凡创新** — 全自主服务机器人,配送/零售/社区服务。偏移动机器人算法、调度系统、场景产品、机器人运营

### 重庆

**人形/四足(本地最纯正,但形态不同于成都)**
- **重庆宇羿科技(宇树科技西部总部,大渡口)** — 2025 年底落地,西部区域总部 + 具身智能机器人西部创新运营中心。与区共建具身智能实验室、四足研发中心、人形数据采集中心、制造基地。招具身智能算法、运动控制算法、算法产品化。**注意:核心研发在杭州总部,重庆偏运营 + 数据 + 场景落地**
- **重庆大学 嘉陵江实验室 + 具身智能实验室** — 王树新院士领衔的人形揭榜挂帅平台;刘景帅做多模态大模型 + 具身(人形/半人形/轮足机器人大脑),王刚做 AI 赋能跨场景精准移动操作。本地人形机器人学术最强力量

**工业机器人本体/控制器(本地传统强项,体量大于成都)**
- **重庆华数机器人** — 华中数控旗下,工业机器人本体 + 控制器,核心零部件自主率超 80%。招电机控制算法、运动控制、硬件、软件。偏工业机器人,非人形/大模型
- **重庆智能机器人研究院** — 两江新区 × 华中数控 × 华中科大共建,本地"一区六平台"核心研发平台。控制器/数控/智能制造,最新向具身机器人创新应用平台(协作机器人)拓展。相当于成都人形中心在重庆的对应物,但偏工业机器人、产业落地更强

**智能驾驶(重庆最大、薪资最高的"具身智能近似岗位"雇主)**
- **长安汽车 / 长安科技 / 长线智能** — 智能网联"链主",研发人员占比 92%、硕博 39%。招 AI 大模型算法、世界模型(3DGS)、智驾预测决策/规控、感知模型、多传感器融合、数据闭环。感知模型算法工程师 35-60k·16 薪
- **赛力斯 / AITO 问界** — 华为系,问界 M9 已在渝获 L3 路测资格。招智能驾驶算法(感知融合预测/规划决策控制/地图定位仿真)。正式岗年薪 30-50 万

**科研院所**
- **中科院重庆绿色智能技术研究院(CIGIT)** — 中科院直属,机器人技术与系统中心(魏大鹏)、推理与认知研究中心(智能体/具身智能)。科研岗以博士为主,编制 + 待遇是本地最好之一
- **北理工重庆创新中心** — 项昌乐院士陆域无人系统研究所,依托智能无人系统国家级重点实验室、无人车工信部重点实验室。偏无人车/陆域无人系统
- **哈工大重庆研究院 + 重庆市智能机器人创新中心** — 智能机器人技术研发、成果转化、产业孵化,2 年内计划孵化 5-10 家机器人企业

**医疗机器人(本地独家辨识度)**
- **重庆金山科技** — 全球首个全自动胃部检查的胶囊内镜机器人(获 CE+NMPA)、胸腹腔手术机器人、MEMS 微系统。在招约 29 岗,均薪约 22.8K
- **重庆山外山(688410)** — 血液净化设备龙头(科创板),三大数据平台 + 智慧辅助系统医工融合项目。偏医疗器械智能化/远程运维

**装备/兵工智能制造**
- **重庆机电集团 / 四联集团(川仪) / 铁马工业 / 长安望江工业** — 装备制造/兵工"母舰"群,机器人方向以集成应用 + 智能制造产线为主,非本体/算法原研

## 本地岗位的共同要求

- **学历:** 核心研发岗偏硕士及以上;优秀本科通常需要在项目、竞赛、论文或真机经验上很强
- **共性技能:** Python / C++ / Linux / ROS-ROS2 / SLAM / 规划与控制 / 多传感器融合 / 模型训练与部署 / 真机调试
- **成都特别有辨识度的能力:** SLAM/导航、机器人软件平台、工业/服务/巡检场景适配、特种场景机器人
- **重庆特别有辨识度的能力:** **智能驾驶感知/规控/世界模型**(与具身大脑技能栈互通,且是本地最高薪岗位)、工业机器人本体/控制器/伺服、运动控制(MPC/LQR/电机控制)、医疗机器人/医学影像 AI、山地/地下特种作业

> 一个关键提示:重庆本地**纯 SLAM 算法工程师岗位比北上深杭少得多**,更多以"智驾感知融合"的形式存在。想做纯 SLAM/导航,成都(绛溪实验室、人形中心)比重庆对口;想做感知/规控/世界模型并拿高薪,重庆(长安/赛力斯)比成都现实。

## 川渝的交叉应用方向

把成都原有 9 大方向与重庆方向合并,形成川渝全景。

### 第一梯队(学校-平台-场景支撑明确)

1. **智能驾驶 + 智能制造(汽车产业链)**【重庆主干道】— 长安/赛力斯、北理工重庆创新中心、重庆理工车辆工程、重邮。BEV/Transformer 感知、世界模型(3DGS)、端到端规控、多传感器融合、车规级工程化。**这是重庆和成都最大的差异点**,年薪 30-50 万,体量远超本地机器人本体岗
2. **轨道交通 + 机器人/巡检**【成都最强】— 西南交大核心场景,高铁箱梁智能巡检、交通装备控制、轨交运维。重庆侧对应:重庆交通大学(交通应用机器人、跨座式轨交、桥隧检测)
3. **电力/核电 + 特种机器人**【成都,常被低估但落地价值最高】— 川大电气 + 上海电气核电场景。电力巡检、核电特种作业、智能装备状态感知
4. **医疗/康复 + 智能医学**【川渝各有特色】— 成都:川大+成电+成中医+华西,康复/手术/医疗物流;重庆:金山科技(胶囊内镜/手术机器人)、山外山(血液净化智慧系统)

### 第二梯队(技术上贴近但更依赖行业周期)

5. **工业机器人本体 + 核心控制器(国产替代)**【重庆传统强项,体量大于成都】— 华数机器人、重庆智能机器人研究院、嘉陵江实验室(人形关节/丝杠)、卡诺普(成都)。控制器/伺服/电机/运动控制/高速高精
6. **人形/四足机器人**【川渝形态不同】— 成都:人形中心(原研);重庆:宇树西部总部(运营/数据/落地)+ 嘉陵江实验室(科研)。重庆有明确的人形团队,但属"应用+数据+孵化"梯队,非原研第一梯队
7. **航空航天/低空 + 感知控制**【成都为主,重庆补充】— 成电航空航天、绛溪实验室;重庆大学航空航天学院(智能飞行器/无人机,推动"无人机向智能飞行机器人转型")
8. **社区服务/配送 + 移动机器人**【成都】— 越凡创新。室内外配送、社区服务、商业零售自动化。重庆本地缺乏越凡那种成熟的服务机器人本体企业

### 第三梯队(想象空间大/政策推动,付费模式待验证)

9. **特种/军工/无人系统 + 山地地下作业**【重庆独家场景】— 北理工重庆(陆域无人系统)、长安望江/铁马、嘉陵江实验室("地下空间复杂环境智能作业机器人"揭榜项目)。重庆"8D 山城"地形带来独家场景,规模不大但辨识度高
10. **银发经济/养老 + 服务机器人**【成都】— 成中医 + 成电生医。陪伴、康复训练、跌倒检测、慢病管理
11. **农业机器人 / 智能农业装备**【重庆(西南大学)】— 立足西南丘陵农业,西南大学承办全国智能农业装备大赛,是西南地区农业机器人最强入口
12. **文旅 + 机器人 / 智能建造**【成都文旅、重庆基建】— 成都人形中心(文旅导览);重庆智能建造机器人(桥隧/山地建筑,重大产研院智能建筑机器人中心)
