# 具身智能行业线索

## 当前判断
- 具身智能已经从“只讲模型故事”进入“真机落地、场景验证、工程闭环”阶段。
- 真正稀缺的不是泛 `AI` 能力，而是能把 `感知 -> 决策 -> 规划 -> 控制 -> 真机部署` 串起来的人。
- 对成都求学和就业来说，不一定只盯“纯人形机器人创业公司”，`控制/机械/机器人/智能装备 + 行业场景` 反而更现实。

## 招聘需求

### 口径说明
- 本节的“当前招聘需求”主要基于 `2025-01` 到 `2026-05` 之间仍可检索到的公开招聘样本、产业人才报告和标准化征求意见稿。
- 其中“学历、技能”的判断，不只看单一公司，而是综合 `人形机器人创新中心、四足机器人公司、机器人算法岗、军工机器人平台` 的共同要求。

### 需求强度
- 参考《2025 年机器人产业人才发展报告》（数据时间 `2025-01` 到 `2025-05`）：人形机器人招聘职位数同比增长 `409%`，其中机器人算法工程师同比增长 `479%`。
- 同一报告显示，机器人产业招聘里技术岗占比 `62%`，机器人算法工程师需求城市前三是 `北京、深圳、上海`。
- 薪资上，人形机器人方向机器人算法工程师平均招聘薪资约 `31512 元/月`，要求 `5 年以上经验` 的算法岗约 `38489 元/月`。

### 学历要求
- 机器人产业技术岗整体要求里，本科占比约 `51%`，硕博占比约 `11%`，本科及以上合计超过 `6 成`。
- 但具身智能核心岗和普通机器人岗不完全一样。公开岗位样本里，`具身算法/VLA/强化学习/SLAM/运动控制` 等核心研发岗更常见的口径是：
  - `硕士及以上`
  - `优秀本科可放宽`
  - 研究岗、世界模型/VLA 岗更偏 `硕士/博士`
- 北京人形机器人创新中心发布的《具身智能从业人员能力要求（征求意见稿）》也基本对应这一趋势：
  - 初级岗通常要求 `1 年左右` 相关研究/开发经历
  - 中级岗通常要求 `3 年以上`
  - 高级岗通常要求 `5 年以上`

### 成都本地招聘样本
- `成都人形机器人创新中心` 的 `SLAM 导航算法工程师`、`规划控制算法工程师（机械臂/足式机器人）` 等岗位，公开口径普遍要求：
  - `硕士、博士及优秀本科生`
  - 专业偏 `计算机、自动化、机器人、机械、信息`
  - 技能偏 `SLAM、导航、路径规划、运动控制、MPC、LQR、NMPC`
- `天府绛溪实验室` 的 `激光 SLAM` 方向岗位，公开要求更偏科研型：
  - `国内外知名高校硕士毕业 2 年以上或应届博士`
  - 要求视觉导航、机器人感知系统方案设计与实现能力
  - 论文和高水平科研经历是加分项
- `中国兵器装备集团自动化研究所有限公司` 的机器人运动控制算法岗，说明军工/特种机器人平台也在成都、绵阳持续布局该方向。

### 具体技能

| 方向           | 常见技能要求                                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------------------------- |
| 具身算法 / VLA   | `Python`、`PyTorch/TensorFlow`、`Transformer`、多模态学习、`VLA/VLM`、监督学习 + 强化学习、`LoRA/P-tuning`、分布式训练、模型压缩、`ONNX/TensorRT` 部署 |
| 仿真与 Sim2Real | `Isaac Gym/Isaac Sim`、`MuJoCo`、`Gazebo`、合成数据、策略训练、`Sim2Real` 迁移                                                       |
| 感知 / 多传感器融合  | 相机、`IMU`、激光雷达原理与标定，`EKF/UKF/图优化`，时空同步，数据对齐，传感器融合                                                                      |
| 定位建图 / SLAM  | `C++`、`ROS`、`Linux`、多视图几何、状态估计、`ORB-SLAM` 等开源框架、视觉惯导、重定位、回环检测                                                         |
| 运动控制         | 运动学、动力学、轨迹规划、轨迹优化、力控、自适应控制、全身控制、`MoveIt/OMPL`、`MATLAB/Simulink`、实时性与稳定性                                               |
| 模仿 / 强化学习    | `PPO`、`SAC`、`GAIL`、奖励函数设计、策略网络设计、样本效率、收敛稳定性、离线强化学习、多智能体强化学习                                                           |
| 工程化落地        | 论文复现、数据清洗与评测、真机调试、跨硬件/算法协作、英文论文阅读、从训练到部署的完整 pipeline                                                                  |

### 对岗位的实际理解
- 具身智能招聘最看重的不是“只会调一个模型”，而是：
  - 能不能复现论文
  - 能不能做仿真
  - 能不能上真机
  - 能不能在 `ROS / Linux / C++ / Python` 的混合工程环境里把东西跑通
- 对软件背景的人来说，离岗位更近的切入点通常是：
  - 机器人软件平台
  - 仿真与数据工具链
  - 感知 / SLAM / 部署工程
  - 3D 可视化、人机交互、测试验证

## 国内公司图谱

### 国央企 / 国资平台
- `国家地方共建具身智能机器人创新中心 / 北京人形机器人创新中心`
  - 北京经开区“国家队”平台，围绕通用机器人平台 `天工`、通用具身智能平台 `慧思开物` 做母平台和测试验证。
  - 公开信息里已与 `京东、优必选` 等合作做仓储物流、工厂分拣、特种作业等试点。
- `国家地方共建人形机器人创新中心（上海）/ 人形机器人（上海）有限公司`
  - 上海市与工信部共建的人形机器人领域国家级创新中心。
  - 已发布 `青龙` 开源公版机、建设训练场，更像“底座平台 + 生态组织者”。
- `上海电气`
  - 已与上海国地中心签约共建人形机器人具身智能训练场，明确往 `核电等特种工业场景` 落地。
- `成都人形机器人创新中心`
  - 成都本地生态值得持续跟踪，当前更偏 `开源平台、展示、实验场景、城市级创新生态`。
  - 从公开招聘和公开采访看，它更像成都具身智能生态的本地抓手，而不只是单一创业公司。

### 合资平台
- `上海发那科`
  - 由 `上海电气集团` 与 `发那科集团` 联合投资，偏工业机器人、自动化产线和智能制造解决方案。
  - 虽然不是“纯具身智能创业公司”，但这类平台代表了中国机器人产业最成熟的落地土壤。
- `安川首钢机器人`
  - 由 `首钢` 与 `安川电机` 合资，是工业机器人和系统集成老牌平台。
  - 如果从就业稳定性和工程训练强度看，这类公司比纯概念型创业公司更扎实。

### 独角兽 / 高热创业公司

#### 已明确进入独角兽口径
- `宇树科技`
  - 已见于 `2025 胡润全球独角兽榜`。
  - 特点是 `四足机器人 + 人形机器人`，同时具备较强的真机工程和出货能力。

#### 高估值 / 准独角兽 / 重点观察
- `智元机器人`
  - 公开融资新闻多次将其按“超级独角兽”口径讨论，`2025-03` 到 `2025-04` 多家媒体报道估值约 `150 亿元`。
  - 优势是量产节奏快、生态动作多，适合持续看招聘。
- `银河通用`
  - 偏 `操作机器人 / 抓取 / VLA`，公开融资新闻显示其估值在 `2025-12` 已到 `30 亿美元` 级别。
  - 如果看算法含量，它在国内属于非常值得跟踪的一档。
- `傅利叶智能`
  - 早期强项在康复机器人，之后向通用人形机器人延展。
  - 更适合看 `医疗康复 -> 通用机器人` 的迁移路线。
- `云深处科技`
  - 四足机器人落地比较务实，巡检、安防、应急等行业场景更清晰。
  - 如果判断“先商业化还是先炫技”，它更偏前者。

### 军采 / 特种场景公开线索
- `2025-09` 军队采购网公开的“机器狗采购项目”招标参数中，已直接出现 `云深处四足轮式机器狗 M20 Pro`。
- `2025-07` 军队采购网“锦州某单位消防灭火机器人采购项目”预中标供应商为 `山东国兴智能科技股份有限公司`。
- 公开军采线索说明几个判断：
  - 军采和特种场景对 `四足/轮足/消防/巡检/物流/医疗` 的需求比通用人形更真实
  - 这类需求更看重 `加密通信、可靠性、国产化、自主运维、极端工况适应`
  - 真正能进军采/特种场景的公司，往往工程能力和交付能力比 demo 能力更重要

## 成都高校相关研究生专业

### 竞争判断方法
- 很多学校不会长期、完整公开 `报录比`，所以这里的“竞争强弱”是替代判断，不是精确排名。
- 主要使用四个代理指标：
  - `复试线`
  - `招生计划`
  - `推免占比`
  - `是否常见调剂`
- 因此这里更适合做择校分层，不适合直接当作唯一报考依据。

## 如果目标是进入具身智能赛道
- 想冲头部算法岗：
  - 优先选 `川大 / 成电 / 西交`
  - 同时补 `Python + C++ + ROS + 仿真 + 论文复现`
- 想走工程落地和性价比路线：
