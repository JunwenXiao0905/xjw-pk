## 职位内容

岗位职责：
1、负责足式 / 人形机器人核心运动控制算法模块研发，包括步态规划、接触⼒优化、全⾝协调控制（WBC/QP）等，具算法设计、实现与调优能⼒；
2、熟练使用 Mujoco / IsaacSim / Gazebo 等仿真平台搭建高保真仿真环境，⽀撑控制算法与强化学习的联合迭代验证；
3、设计并实现机器人运动控制相关强化学习算法，完成奖励函数设计、策略训练及基础课程学习方案落地；
4、研究控制与学习融合基础方法，如 RL Residual Control，提升机器人运动稳定性与适应性；
5、负责控制算法与 RL 策略的工程化实现，包括状态估计、传感器融合等模块开发，完成仿真到实机的初步迁移；
6、优化算法在实时系统（ROS2/C++）中的执行效率，确保满足基础实时性要求，参与解决联调过程中的技术问题；
7、与机械、电气团队高效协作，推进算法在真实硬件上的验证与性能优化，输出完整技术文档。
任职要求：
1、硕士及以上学历，自动化、控制工程、机器人、电子信息、人工智能等相关专业，3-5 年机器人算法或控制相关工作经验；
2、具备扎实的数学基础，精通运动学 / 动力学求解，熟练使用 Pinocchio、Drake 或 RBDL 等至少一种动力学库；
3、深入理解足式 / 人形机器人控制方法（QP、WBC 等），具备独立算法开发、调参及问题排查经验；
4、熟悉强化学习核心框架（PPO、SAC、TD3）及相关开源项目，具备奖励函数设计、策略训练的实际落地经验；
5、掌握至少两种仿真平台（Mujoco / IsaacSim 优先），具备高保真仿真环境构建与算法验证实战经验；
6、具备真实机器人调试经验，了解传感器融合、状态估计（如卡尔曼滤波）等工程要点；
7、精通 C++ 与 Python 开发，熟练掌握 ROS2 与多线程编程，能够独立完成算法工程化部署；
8、了解 sim2real 基础方法（如域随机化），具备简单策略迁移实践经验；
9、具备良好的工程实现能力、问题分析能力与跨团队协作能力，能高效推进项目落地。
