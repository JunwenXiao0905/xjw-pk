## 职位内容

岗位职责：
1、主导足式 / 人形机器人核心运动控制算法体系设计，包括⾼阶步态规划、NMPC 控制、全⾝协调控制等关键技术研发与突破；
2、牵头搭建 Mujoco / IsaacGym 等⾼性能仿真平台，设计强化学习与控制算法联合迭代架构，支撑复杂算法快速验证；
3、深入研究控制与强化学习融合前沿⽅法（Model-based RL、MPC+Policy 等），攻克机器人稳定性、自适应能力等核心技术难题；
4、负责复杂控制算法与 RL 策略的实机部署全流程，包括高精度状态估计、多传感器融合、接触判定等关键模块研发；
5、主导解决 sim2real 迁移核心问题，通过随机化、域自适应、策略蒸馏等技术，大幅提升仿真策略向实机迁移的成功率；
6、优化控制器与 RL 模型在实时系统（ROS2/C++/RT）中的执行效率，确保满足 1–5ms 严格控制周期要求；
7、带领技术团队推进算法从仿真到实机的完整落地，主导跨机械、电气、嵌入式团队的联调工作，解决关键技术瓶颈；
8、跟踪行业前沿技术趋势，制定技术研发路线，推动团队技术能力提升与创新突破。
任职要求：
1、硕士及以上学历，自动化、控制工程、机器人、人工智能等相关专业，5 年以上机器人运动控制算法研发经验，具备足式 / 人形机器人相关项目核心研发经历；
2、具备深厚的数学与控制理论基础，精通运动学 / 动力学求解，熟练运用多种动力学库（Pinocchio、Drake、RBDL）进行复杂系统建模；
3、深入掌握足式 / 人形机器人高阶控制方法（QP、WBC、NMPC 等），具备大规模复杂算法体系设计与工程化落地经验；
4、精通强化学习前沿框架与开源项目（Isaac Lab / Isaac Gym），在奖励函数设计、策略训练、课程学习等方面有深度积累；
5、对控制 + 强化学习融合方法（Residual Policy、Model-Based RL 等）有深入研究与实战落地经验，能解决复杂场景下的技术难题；
6、熟练掌握多种高性能仿真平台，具备复杂高保真仿真环境构建与算法验证体系搭建能力；
7、具备丰富的真实机器人调试经验，精通传感器融合、状态估计、实时控制等工程核心技术；
8、精通 C++ 与 Python 高级开发，深入理解 ROS2 架构与实时系统优化，能独立解决算法部署中的高实时性、高可靠性问题；
9、对 sim2real 技术有系统研究与成功实践经验，能主导解决复杂策略迁移难题；
10、具备优秀的技术领导力、项目管理能力与跨团队协作能力，能带领团队攻克技术难关，推动产品化落地
