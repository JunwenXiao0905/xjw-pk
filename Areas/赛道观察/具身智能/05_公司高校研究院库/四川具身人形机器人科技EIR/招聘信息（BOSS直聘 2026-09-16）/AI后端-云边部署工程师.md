## 职位内容

岗位定位： 负责 Agent Runtime 的服务化、云边协同、机器人端部署、通信链路、日志监控和系统稳定性建设。
核心职责：
1. 负责 Agent Runtime 后端服务开发，包括用户管理、会话管理、任务管理、⼯具调⽤、⽇志记录等模块。
2. 负责机器人端与云端之间的通信架构设计，包括 WebSocket、gRPC、MQTT、HTTP API 等。
3. 负责大模型 API、RAG 服务、语⾳服务、机器人 Skill 服务的统一接入与管理。
4. 负责边缘端部署、Docker 化、服务守护、异常恢复和弱网容灾。
5. 建设日志、监控、链路追踪和数据回放系统，支持 Agent 效果分析与问题排查。
6. 支持多机器人、多场景、多客户的部署和配置管理。
任职要求：
1.本科及以上学历，计算机、软件工程、人工智能等相关专业。
2.熟悉 Python / Go / Node.js 至少一种后端开发语言。
3.熟悉 FastAPI、Flask、Gin、NestJS 等一种或多种后端框架。
4.熟悉 Docker、Linux、Nginx、数据库、消息队列、缓存等基础组件。
5.熟悉 WebSocket、gRPC、MQTT、RESTful API 等通信方式。
6.有较强系统稳定性意识，能够处理部署、监控、日志、异常恢复等工程问题。 加分项：
1.有 AI 平台、大模型应用平台、机器人云平台、IoT 平台开发经验。
2.熟悉 Kubernetes、Prometheus、Grafana、ELK、OpenTelemetry。
3.熟悉边缘计算、端云协同、设备管理。
4. 有 ROS2 Bridge 或机器人通信系统经验。
