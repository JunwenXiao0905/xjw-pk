## 职位内容

岗位定位： 负责公司机器人 Agent Runtime 的整体技术架构设计与落地，是智能交互系统的核心技术负责人。
核心职责：
1.负责机器⼈ Agent Runtime 整体架构设计，包括多 Agent 调度、⼯具调⽤、任务规划、记忆系统、RAG、状态管理等核心模块。
2.设计大模型与机器⼈本体能力之间的调用机制，实现语言理解、任务决策、动作执行之间的闭环。
3.负责 Agent Runtime 与机器人控制、导航、动作、表情、语音、投影等系统的接口设计。
4.设计云边协同架构，支持云端复杂推理与机器人端低延迟执行。
5.负责技术路线选型、核心模块开发、代码架构管理和团队技术推进。
6.建立 Agent Runtime 的稳定性、安全性、可扩展性和可交付能力。
任职要求：
1.本科及以上学历，计算机、人工智能、机器人、自动化等相关专业。
2.熟悉 LLM Agent 架构，理解 Tool Calling、Function Calling、Workflow、Planner、Memory、RAG 等核心机制。
3.熟悉 LangGraph、AutoGen、CrewAI、OpenAI Agents SDK、Dify、Coze、MCP 等一种或多种 Agent 框架或相关思想。
4.具备较强后端系统架构能力，熟悉 Python / Go / C++ 至少一种语言。
5.熟悉状态机、行为树、任务编排、服务化架构。
6.有较强工程落地能力，能够从 0 到 1 搭建复杂 AI 系统。
加分项：
1.有机器人、智能硬件、车载语音、智能座舱、服务机器人项目经验。
2.有 Agent Runtime、AI Workflow 平台、智能体应用平台建设经验。
3.熟悉 ROS2、机器人 Skill API、边缘计算部署。
4.有技术团队管理经验。
