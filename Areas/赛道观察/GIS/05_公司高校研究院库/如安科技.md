## 评估

- **画像**：项目制交通安全 SaaS——乙方交付模式，实施岗占一半；20-99 人撑 7 家分支 + 30 城服务，人均产出压力大
- ✅ **最大价值是比价样本**：同公司同学历同经验档的 GIS 岗，成都 9-13K（实施实质）vs 苏州 15-25K（真开发）vs 上海"高级"15-25K——一次抓出三个市场规律：**城市价差 + 岗种借 title + 头衔通胀**
- ✅ Java 浓度高于 GIS（4 条 Java 开发 vs 2 条 GIS 真开发），且苏州 Java 数据/AI 方向给到 13-18K——A 路线（不提学历走 Java）在成都本地公司的微观印证
- ⚠️ 薪资带 9-25K·13薪 属赛道中低位；A 轮小体量，"自动驾驶场景库"业务线若属实是唯一向上叙事（与智驾数据方向交集），值得留意但未验证
- 📌 定位建议：成都本地"GIS 实施/初中级开发"保底样本（9-13K 是成都 GIS 实施行情价）；若走开发岗，其苏州岗（15-25K）技术栈（Java+PostGIS+OGC+QGIS）就是准备清单
