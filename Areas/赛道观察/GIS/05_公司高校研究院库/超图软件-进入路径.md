# 超图软件 — 国产 GIS 商业龙头的进入路径

> 调研时间：2026-09-01；来源：[超图官网](https://www.supermap.com/zh-cn/a/product/gis-web-2025.html)、[官方招聘页](https://www.supermap.com/zh-cn/a/job/list_13_1.html)、[iClient 官网](https://iclient.supermap.io/)、[GitHub](https://github.com/SuperMap/iClient-JavaScript)、BOSS直聘/职友集样本
> 起因：信创替代 ArcGIS 的需求信号（[微信文章](https://mp.weixin.qq.com/s/KTYmv1tRvUjQAyYuK6CO3A)）+ 想弄清"产品不开源，怎么准备才能进超图"

## 一句话画像

国产 GIS 平台软件龙头，对标 ArcGIS 全家桶（信创替代主力）。核心产品（GIS 内核、iServer 服务端、iDesktop 桌面）**闭源收费**；但 Web 客户端 **iClient JavaScript 完全开源（Apache-2.0）且构建在 OpenLayers / Leaflet / MapboxGL / MapLibre 等开源库之上**——所以"学开源栈进超图"不是曲线，是正门。

## 2. 开源与免费的真实边界

- **闭源收费**：GIS 内核、iServer、iDesktop——这是它的商业模式，也决定了政企信创验收点名它时的护城河
- **开源免费**：iClient JavaScript 核心代码 [Apache-2.0](https://github.com/SuperMap/iClient-JavaScript/blob/master/LICENSE)，可商用；且它不是从零写的引擎，而是**封装/集成开源地图库**（OpenLayers、Leaflet、MapboxGL、MapLibre）+ 可视化库
- 含义：**超图前端岗所需的技术栈，几乎全部可以基于开源材料自学**；闭源的只是服务端与内核的实现细节，那是入职后的事

## 4. 结论：研究什么可以进超图

核心认知修正：**"不开源所以只能曲线救国"这个前提不成立。** 超图闭源的是内核实现，但它的技术栈"语言层"全是开放的——OGC 标准、开源前端库、图形学、Java 服务端。按岗位分：

| 目标岗位 | 可自学的准备路径（全部开放材料） |
|---|---|
| Web 前端 / WEBGIS 开发（最顺的路） | **就是现在在学的开源栈**：OpenLayers / MapLibre / Cesium + Vue3；直接读 iClient 源码（Apache-2.0），它怎么封装这些库就是面试素材；关注其 WebGPU 渲染方向（与《地图引擎行业技术现状报告》§3.3 呼应） |
| 三维开发 | C++ + OpenGL/Vulkan + 渲染管线 + 点云处理（PDAL 等开源工具练手）——图形学是通用能力，不依赖超图内核 |
| 服务端 Java | Java + Spring + **OGC 服务标准**（WMS/WFS/WMTS/3D Tiles，规范全公开）+ PostGIS；拿 GeoServer 做开源自习对照（iServer 的对标物） |
| AI 方向（新机会） | GIS 智能体服务平台（2025 Beta）刚起步，与 GIS+AI 赛道交叉——空间智能 + Agent 是差异化切入点 |

共同底座（所有岗位通用）：OGC 标准、空间数据库（PostGIS）、坐标系与空间分析基础——与库里"空间数据工程"专项的能力清单一致。

**附加观察**：超图 iClient 2025 支持 WebGPU 双引擎，是国产商业厂商采用 WebGPU 的先行信号（Esri 至今未动）——写入《地图引擎行业技术现状报告》§3.3。
