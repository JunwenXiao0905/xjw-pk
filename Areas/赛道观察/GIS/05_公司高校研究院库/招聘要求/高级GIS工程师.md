岗位职责 
1.负责GIS空间分析算法的设计、开发、优化与工程化 落地，攻克复杂空间计算难题，保障算法高效稳定运 
2.独立承担前端地图可视化或后端空间数据服务开发 工作，兼顾前后端能力者优先。
3.基于 PostGIS、GDAL/OGR开展空间数据全流程处 理，完成数据格式转换、投影转换、矢量/栅格数据分 析等工作。 
4.研发高性能空间计算模块，实现几何计算、空间索 引、拓扑分析、缓冲区分析、叠加分析等核心功能。 
5.参与整体 GIS系统架构设计、技术选型，保障空间数 据服务的高稳定性、高性能与可扩展性。 
6.深度参与智慧农业、智慧水利、综合能源等行业项目 建设，负责空间数据管理、地图可视化、空间分析服务 等模块开发。 
7.结合业务场景，完成农业地块、水利流域、管网线 路、能源场站等专题空间数据分析与可视化应用开发。 

任职要求
（一）基本要求
1.本科及以上学历，GIS、计算机、测绘、遥感、水利、 农业工程等相关专业优先。
2.具备3年及以上全职 GIS开发经验，拥有完整GIS项 目全流程开发、交付或核心模块独立开发经验。 
3.至少深耕农业、水利、能源其中一个行业，熟悉对应 业务场景（农田管理、灌区调度、流域分析、水资源调 度、管网/输电线路/油气管线运维、新能源场站管理 等）。 
4.精通空间数据基础理论，熟练掌握矢量、栅格、遥感 影像、DEM 等主流空间数据类型与应用逻辑。 

(二）算法能力（核心要求) 
1.掌握计算几何基础知识，熟悉凸包、Voronoi 图、 Delaunay 三角剖分、多边形布尔运算等常用算法。 
2.精通缓冲区分析、叠加分析、网络分析、空间插值、 等值线生成等经典空间分析算法。 
3.理解 R-Tree、! 四叉树、GeoHash 等主流空间索引结 构，熟悉坐标系、投影转换、空间参考系统原理。 
4.具备流域分析、坡度坡向分析、汇水分析、管网连通 性分析、路径规划等实战经验者优先。 

（三）技术栈要求（后端/前端二选一，全栈优先）
后端 开发方向: 
1.熟练使用Golang 语言及Gin 框架，掌握 GORM 组件 使用;
2.精通 PostgreSQL+PostGIS，可独立编写复杂空间查 询语句，熟练运用各类空间函数； 
3.熟悉 GDALIOGR 数据处理流程，拥有 GDAL C API 二次开发经验者优先: 
4.具备 REST API设计与开发能力，了解空间数据服务 接口规范; 
5.有大规模空间数据处理、查询性能优化、异步任务处 理经验优先。

前端开发方向： 
1.熟练使用 Vue3，具备标准化组件化开发能力; 
2.精通Mapbox GL JS，可独立实现矢量瓦片加载、 层控制、交互查询、空间可视化等功能 
3.可根据业务定制专题图、轨迹展示、区域高亮、交互 式空间查询等地图功能; 
4.了解 WebGL、Shader、自定义渲染技术，具备海量 点线面可视化优化经验者优先。 

(四）加分项 
1.拥有农业、水利、能源行业大型 GIS平台独立建设经
2.熟悉农田、灌区、河道、水库、流域、管线、能源场 站等行业专属空间业务数据 
3.具备遥感影像处理、水文分析、土地利用监测、作物 识别、新能源选址、线路巡检等项目经验;
4.掌握 GDAL C API二次开发，有亿级空间要素处理、 矢量瓦片切片、地图服务性能优化经验; 
5.了解三维 GIS、点云、倾斜摄影、BIM+GIS 融合技 术;
6.有开源 GIS项目贡献、个人技术作品或技术博客者优 先。
