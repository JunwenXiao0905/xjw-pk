一、岗位职责
1. 全栈开发任务：负责项目后端核心模块及前端交互界面的开发⼯作；主导服务器架构设计，确保系统具备⾼扩展性、⾼可用性及良好的用户体验。
2. AI辅助研发：结合AI编程⼯具进行代码编写与重构，提高开发效率与代码质量，探索AI在业务逻辑生成、单元测试编写等场景的应用。
3. 设计与交付：根据产品需求完成前后端分离架构设计、数据库建模、编码、单元测试、集成测试以及相关技术文档的编写。
4. 性能攻坚：持续优化系统响应速度与并发处理能力，解决数据库慢查询、缓存策略失效、JVM内存溢出等疑难问题。
二、任职要求
1. 具备扎实的 Java 编程基础，深入理解 JVM、多线程、集合等核心机制，代码规范、可读性与可维护性强；
2. 熟练掌握 Spring Boot、Spring Cloud 等微服务开发框架，有分布式系统设计与落地经验；
3. 熟悉微服务架构下的服务注册与发现机制，熟练使用 Nacos、Eureka 等组件，并理解其原理、配置方式及在高可用场景下的使用；
4. 熟悉 PostgreSQL（PG）数据库，掌握表结构设计、索引优化、SQL 调优及常见高并发场景下的数据库实践；有 MySQL / Oracle 使用经验者更佳；
5. 熟悉常用中间件：Redis、消息队列（Kafka / RabbitMQ / RocketMQ 等）、Elasticsearch、Nginx 等，并了解其典型使用场景与性能要点；
6. 熟练掌握前端 Vue（Vue2 / Vue3）及相关生态（Vue Router、Pinia / Vuex、Element Plus 等），能够独立完成前后端联调与页面开发；
7. 有使用 AI 编程工具（如 GitHub Copilot、通义灵码、Cursor 等）提升编码效率的实践经验，能在代码生成、重构、单测编写等场景合理使用；
8. 思路清晰、责任心强，能承受一定压力，具备良好沟通能力与团队合作精神；
有不动产登记、自然资源行业业务系统开发经验者优先。
