# 遥感智能算法 - 方向定位

## 这是什么
用深度学习做遥感影像理解与信息提取。区别于 [[空间数据工程]]（向量/拓扑数据的存储与挖掘）和 [[地图引擎]]（渲染层），本方向聚焦**栅格/影像数据的智能处理**。

## 为什么纳入这个方向
1. **遥感 GIS 不分家**：地信本科遥感课程训练的内容（影像分类、地物提取、变化检测）正是本方向的传统根基，有科班基础。
2. **深度学习让遥感算法门槛降低**：经典遥感算法（监督分类、波段运算）正被 DL 重构，PyTorch + 遥感数据成为新主流，上手路径比传统 ENVI/IDL 更开放。
3. **衔接多个赛道**：
   - 互联网地图（字节影像挖掘岗——道路感知、变化检测、路网自动生产）
   - 航空航天（卫星遥感、商业航天——见 [[../../行业方向观察/航空航天]]）
   - 自然资源/农业/环保/国防（经典遥感应用市场）

## 明确的边界（防止漂移）
- **本方向对标"遥感+深度学习"，不是"纯 CV 算法"**。字节影像挖掘岗虽然 JD 写 CV，但其业务场景（道路/地物变化）本质是遥感影像理解，遥感背景是杠杆，不是负债。
- **不碰纯大模型后训练**（如 A142069A 多模态大模型岗的核心：Post-Training/RL/蒸馏）——那是 LLM/VLM 专家的领域，GIS 背景无优势，列为观望。
- **核心是"用 DL 解决空间影像问题"**，不是"成为 DL 专家"。两者的学习重点完全不同。

## 对标就业市场
- **互联网地图（高门槛，北极星）**：字节影像挖掘算法（A171465）、影像/轨迹挖掘算法（A24410B）——见 [../../招聘要求/字节/04-算法方向招聘要求.md](04-算法方向招聘要求.md)
- **遥感应用市场（现实落点）**：航天/自然资源/农业/环保/国防领域的遥感算法岗——待补充收集
- 现实判断：互联网影像岗要求 CVPR/ICCV 论文，地信本科入围概率低，**作为能力北极星**；遥感应用市场对学历更友好，是现实求职落点。

## 核心能力清单（持续对照补齐）
- [ ] 遥感基础回顾（影像类型、波段、辐射/几何校正、分辨率）— 本科有基础，需激活
- [ ] Python + PyTorch 基础（张量、训练循环、模型保存）
- [ ] 遥感影像的 DL 数据处理（rasterio、GDAL、大影像切分/分块）
- [ ] 目标检测（YOLO 系列 / Faster R-CNN，用于地物提取）
- [ ] 语义分割（U-Net / DeepLab，用于地物分类、变化检测）
- [ ] 变化检测（双时相影像对比，遥感特色任务）
- [ ] 大影像推理优化（切分、拼接、边缘处理）
