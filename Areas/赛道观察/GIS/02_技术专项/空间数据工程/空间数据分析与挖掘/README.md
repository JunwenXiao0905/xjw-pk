# 空间数据分析与挖掘

## 这是什么
在空间数据之上做计算：聚类、匹配、拓扑分析、模式发现。核心问题：如何从海量空间数据里提取结构、关系和模式。

## 对应当前工作的哪一段
- **轨迹聚类**：对用户轨迹做聚类，发现热门路线 / 用户行为模式
- **重叠检测**：判断多条轨迹是否经过同一路段（本质是地图匹配 / 路段合并的简化版）
- 这是本方向最直接的实战出口，也是 GIS 背景差异化最强的区

## 学习重点（按优先级）
1. **Python 空间数据处理栈**
   - GeoPandas、Shapely、NumPy（对标 JD 明确要求）
   - 重点：复杂空间处理的性能优化（JD 提到"爆内存"问题）
2. **空间聚类算法**
   - DBSCAN、HDBSCAN（密度聚类，适合轨迹/POI）
   - 图聚类、启发式合并（JD 提到）
   - 理解每种算法的业务约束（POI 上限、面积上限、形状规整性）
3. **空间关系与拓扑操作**
   - intersects / contains / overlay / polygonize（JD 原文）
   - 几何有效性、拓扑稳定性（实战痛点）
4. **地图匹配 / 重叠检测原理**
   - 当前工作的理论支撑，把"重叠检测"从工程 trick 上升到可讲清的算法
