# 空间数据存储与索引

## 这是什么
空间数据的持久化存储、建模、索引与检索。核心问题：如何让海量空间数据"存得下、查得快、改得动"。

## 对应当前工作的哪一段
- **轨迹数据清洗入库**：把原始轨迹清洗后写入数据库，设计 schema
- 这是本方向最直接的实战出口

## 学习重点（按优先级）
1. **PostgreSQL + PostGIS**
   - 空间扩展、几何类型（geometry/geography）
   - 空间索引：GiST、BRIN（重点理解为什么空间索引不能用普通 B-tree）
2. **空间索引原理**
   - R-tree、Grid Index、Geohash、H3（Uber）、S2（Google）
   - 每种索引适合什么场景（点查询 vs 范围查询 vs 聚合）
3. **轨迹/路网数据建模**
   - LineString 的存储与版本管理
   - 路网拓扑（节点-路段关系）如何建模
4. **检索引擎**
   - 空间范围查询、最近邻查询（KNN）
   - 海量数据下的查询性能优化
