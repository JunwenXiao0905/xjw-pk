# 三维重建行业线索

## 前沿技术

- **ABot-Recon：无长程依赖的万帧级流式 3D 重建基础模型**（高德 AMAP CV Lab，2026-08-28 开源）
  - 核心创新：摒弃流式重建普遍依赖的长程记忆锚点，**固定 12 帧局部上下文窗口**，每步预测当前帧局部点图 + 相邻帧相对位姿，在线组合出全局轨迹与点云 → **显存与单帧计算量与视频长度无关**，默认支持 22000 帧
  - 技术路线：局部位姿预测 + 残差优化；KV-cache 缓存 11 帧；轻量运动-视觉旋转精化器抑制漂移；回环检测（DINOv2-SALAD 检索 + 位姿图优化）为可选后端
  - 输入门槛：**单目 RGB 视频即可**，无需深度传感器、无需相机内参
  - 基准数据：Oxford Spires ATE 4.35m（较 LingBot-Map 降低 40.6%）、RPE-R 0.12°（较前代 SOTA 低约 40%）、稠密重建 CD 1.37m / F1 91.81%；KITTI、VBR 同为最低误差
  - 效率：KITTI-02 上 24.45 FPS、峰值显存 6.71 GiB（H100，504×280），GTX 1080Ti 即可运行
  - 谱系：基于 Pi3 构建，受 CroCo / DUSt3R / DINOv2 启发，与 SLAM3R（北大，CVPR 2025）同属"点图回归 + 前馈网络"路线；对比锚点 LingBot-Map
  - 开源状态：推理 + 评测代码与权重已放出（代码 Apache 2.0，权重单独许可）；**训练代码承诺 2026-09-30 前发布**；同团队另有 ABot-Earth
  - 仓库：https://github.com/amap-cvlab/ABot-Recon ｜ 论文：arXiv 2608.27529（*Revisiting Local Context for Long-Horizon Streaming 3D Reconstruction*）｜ [魔搭在线体验](https://modelscope.cn/studios/amap_cvlab/ABot-Recon/)
  - 已在本地跑通验证 → [[ABot-Recon 部署实战]]

## 技术版图（2026）：视频三维重建的三大范式

按"怎么算"分三代，其余差异（在线/离线、输出表示、输入设备）为正交轴：

| 范式 | 代表 | 原理 | 特点 |
|---|---|---|---|
| 传统几何优化 | COLMAP（SfM+MVS）、ORB-SLAM/VINS/FAST-LIO、无人机倾斜摄影（大疆智图/Metashape） | 特征匹配+BA+深度融合，迭代优化 | 准但慢、怕弱纹理；测绘精度担当 |
| 神经优化式 | NeRF（2020）、3DGS（2023） | 每个场景训练一个模型 | 照片级渲染（新视角合成），非量测；需上游给位姿 |
| **前馈式（feed-forward）** | DUSt3R 系 → ABot-Recon | 大网络一次前向直接吐几何 | 2024 起爆发，易用性革命，正在吃前两代地盘 |

- **3DGS 澄清**：它是"表示+渲染"方案（照片级好看），自身不做重建前端；典型 pipeline 是 COLMAP/前馈模型出位姿点云 → 再训 3DGS 渲染。与 ABot-Recon 是**上下游**而非竞品
- **无人机点云建模**：倾斜摄影（SfM+MVS，受控采集换厘米级精度）与机载 LiDAR——传统范式的产业形态，"贵设备+专业作业+离线"；ABot-Recon 反其道（消费单目+随手拍+实时），以精度换便利

**前馈家族谱系**（本方向两年迭代史）：

- DUSt3R（CVPR 2024，开山：双图回归 pointmap，免标定免位姿）
- MASt3R / Fast3R / Spann3R（2024–25，特征匹配、多图、流式尝试）
- VGGT（CVPR 2025 **Best Paper**，单次前向数百图：位姿+深度+点云）
- SLAM3R（北大，CVPR 2025 Highlight）／MASt3R-SLAM：前馈实时稠密 SLAM——**ABot-Recon 所属分支直系**
- Pi3（2025.7，置换等变+KV cache 线性复杂度）——**ABot-Recon 基于 Pi3 构建**
- LingBot-Map（蚂蚁灵波 Robbyant，2026.4 开源）：纯自回归流式，20 FPS、2.5 万帧不漂移，靠几何上下文注意力维护长期记忆
- ABot-Recon（高德，2026.8）：反向差异化——**砍长程记忆**，12 帧窗口+残差优化，显存恒定
- 国内大厂对垒：蚂蚁（4月）vs 高德（8月）四个月内先后开源同赛道模型，均指向具身智能空间记忆/私域建图基建位

综述参考：[Feed-forward 3D Reconstruction: From DUSt3R to VGGT (arXiv 2507.08448)](https://www.alphaxiv.org/zh/abs/2507.08448)｜[知乎前馈3DR深度解读系列](https://zhuanlan.zhihu.com/p/1978442593336575705)

## 岗位对标（对照库内 JD，2026-08 检索）

库内相关 JD 六份：华测导航×3（视觉SLAM 35-60K／三维重建 25-35K／三维重建 18-22K）、四维图新×1（SLAM泊车 20-35K）、天府绛溪实验室×2（SLAM专家／VSLAM）。结论：

- **存量岗位主流栈仍是传统 SLAM**：6 份中 5 份主体要求 = C++ + ORB-SLAM/VINS/LIO-SAM + 李群李代数/BA/卡尔曼 + 多传感器紧耦合融合（VI/LI/GNSS/IMU）。前馈式重建在这些 JD 里只是"跟踪前沿"级加分项
- **明确点名为本方向招聘的**：天府绛溪·交互人形机器人 VSLAM 岗——职责原文"探索 NeRF、3DGS 等技术在机器人领域的应用，通过深度学习的方法构建空间感知和三维重建能力"；华测三维重建岗要求"深度学习与传统 MVS 融合"。此类"空间感知+深度学习"岗在具身智能厂商中比例上升
- **技能栈错位提醒**：专研 ABot-Recon 这类前馈模型练的是 Python/PyTorch/模型复现/数据管线，对应画像"AI算法工程师（3D/空间方向）"；而经典 SLAM 岗硬门槛是 C++ 工程能力与优化数学。**两者在 JD 上是不同岗位，跨投需要补另一侧**
- 可行策略：以前馈重建为差异化亮点 + 补 C++/传统 SLAM 基本功（JD 硬门槛不满足连简历关都过不了）；本地对标单位：天府绛溪实验室·时空AI感知技术创新中心（成都）
- **实证案例（2026-08-31）**：[[数字绿土]]（LiDAR 厂商，Pre-IPO）2027 届校招直接开设 **3DGS 算法工程师 ×3**（成都/武汉/北京）——JD 要求 SfM/MVS/NeRF/3DGS + COLMAP/OpenMVS + LiDAR 点云 AI，正是上述"传统几何 × 深度学习"交叉画像的活体样本；且其同地 SLAM 岗仍为纯传统栈（C++/李群李代数/EKF），一司两岗清晰映照两种岗位物种
