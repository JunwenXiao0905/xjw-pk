## 前沿技术

- **GeoAgent：层级化多智能体空间分析框架**（浙大团队，2026）
  - 基于 LangGraph 构建，三层架构：规划层 → 执行层 → 审查层
  - 八大智能体：Planner / Manager / Coder / Cartographer / Reporter / Reviewer×3
  - 147 项空间分析任务，GPT-4o 成功率 94.56%，DeepSeek-V3 成功率 95.24%
  - 核心技术点：自我纠错闭环、跨 Agent 上下文传递、自主知识推理（如自动识别平方度问题并选用 Albers 等积投影）
  - 论文：IJGIS 2026, DOI: `10.1080/13658816.2026.2624784`

- **GeoJSON Agents：GeoJSON 与多智能体 LLM 框架的系统集成**（浙大/港大，2025）
  - 首次将 GeoJSON 数据与多智能体 LLM 框架系统性结合
  - 对比两种主流 LLM 增强路径：**Code Generation**（97.14%）vs **Function Calling**（85.71%），均大幅领先标准 LLM（48.57%）
  - 架构：Planner 智能体（任务分解）+ Worker 智能体（通过 API/Python 执行空间数据处理）
  - 70 个空间分析任务评测，涵盖 3 个复杂度等级
  - 论文：arXiv 2509.08863, https://arxiv.org/abs/2509.08863

## GIS+AI 落地观察（并入自 前沿技术观察/GIS+AI，2026-09-01）

GIS+AI 有明确行业归属（超图、易智瑞、高德、ArcGIS 等厂商动态），不属于"跨行业前沿候审区"，故并入本专项。

### 当前判断
- `GIS+AI` 已经不只是概念，开始出现多家厂商和具体案例
- 这一条线值得重点看谁能把数据、平台、模型、场景真正打通

### 事件与线索
- 已看到超图、易智瑞、高德、`ArcGIS`、`Cesium MCP` 等案例
- 重点不是单点 AI 功能，而是是否进入真实 GIS 工作流

### 观察方法
- 看是做 `AI for GIS` 工具增强，还是做 `GIS for AI` 空间数据底座
- 看是否进入规划、测绘、城市治理、交通、应急、低空等真实场景
- 看产品里是否出现智能检索、空间问答、自动制图、空间分析 Agent、三维场景交互

**点名要的技术方向**：

- 无人机：即时航测、动态巡查、应急响应、三维重建
- 无人船：水域监测、水下地形、边界巡逻、水文数据采集
- 具身智能：空间感知 + 机器人/机械臂协同作业
- AIoT：边缘感测 + 多模态数据流 + 云端实时决策
- 智能体：多智能体自主调度、协同决策、数字孪生驱动
- 数据×生态：多源数据融合、要素流通、可视化决策引擎（呼应国家数据要素政策）

**场景举例**：智慧城市感知网、水库大坝安全监测、生态红线巡查、港口自动化调度、灾害应急指挥、农业精准变量作业——要求"从演示推向量产"。

**对技术方的要求**：具备成熟 GIS 平台或自研算法，能处理实时动态、多源异构数据；"不只懂静态制图，更懂实时分析、智能预测、协同控制"；有 AI/IoT/自动化整合能力，无人机/无人船项目经验优先。
