# 遥感影像深度学习

## 这是什么
用深度学习模型处理遥感影像（卫星/航空/无人机/车载），完成目标检测、地物分割、变化检测等任务。

## 和"空间数据工程"的区别
|        | 空间数据工程（向量）                | 遥感影像深度学习（栅格）            |
| ------ | ------------------------- | ----------------------- |
| 数据类型   | 向量（点/线/面/拓扑）              | 栅格（影像像素）                |
| 核心工具   | PostGIS、GeoPandas、Shapely | PyTorch、rasterio、GDAL   |
| 核心算法   | 空间聚类、图算法、拓扑运算             | CNN、Transformer、分割/检测模型 |
| 当前工作对口 | 高（轨迹聚类/重叠检测）              | 低（当前项目无影像处理）            |

## 学习重点（按优先级）
1. **Python + PyTorch 基础**
   - 训练循环、数据加载、模型保存
   - 这是所有 DL 的地基，必须先过这关
2. **遥感影像的 DL 数据处理**
   - rasterio / GDAL 读写
   - 大影像切分（tiling）、分块、边缘重叠处理（遥感特有难题）
   - 多波段数据处理（区别于普通 RGB 图片）
3. **语义分割（地物分类、变化检测的基础）**
   - U-Net（遥感最经典）、DeepLab
   - 实践：对遥感影像做地物提取（建筑/道路/水体）
4. **目标检测（地物提取）**
   - YOLO 系列（速度快，工程友好）/ Faster R-CNN（精度高）
   - 实践：检测特定地物（如车辆、建筑）
5. **变化检测（遥感特色任务）**
   - 双时相影像对比，检测地表变化
   - 这是字节影像挖掘岗（A171465）的核心业务之一
