# 四维图新 — 从地图公司到具身智能"数据裁判"

> 来源：微信公众号「产业大数据产品」《一个地图公司，悄悄当上了具身智能的"数据裁判"》（GW，2026-08-08）

## 一句话画像

国内地图/智能驾驶数据老牌厂商（20+ 年），以"数据底座"而非造机器人的姿势切入具身智能，2026年7月拿下工信部具身智能数据标准工作组（WG7）组长单位，CEO 程鹏任组长——从参与者变成规则制定者。

## 1. 为什么地图公司能做具身智能

手里四样稀缺资源，从智能车时代平移到机器人几乎零损耗：

| 稀缺资源     | 在机器人端的对应需求        |
| -------- | ----------------- |
| 甲级测绘资质   | 数据采集的准入门槛         |
| 数据合规工具链  | 机器人摄像头持续采集的敏感数据处理 |
| 高精度定位技术  | 机器人定位与路径规划        |
| 海量时空数据积累 | 环境感知训练素材          |

机器人感知环境、判断位置、规划路径，本质仍是时空信息那一套；机器人的摄像头就是"眼睛"，感知逻辑与智能车一致。

**切入姿势：不造机器人，做数据底座。**

## 2. 智能体数据综合解决方案（2026年4月北京车展发布）

四层架构，"三层打底，一层落地"，从采集→治理→训练评测→合规流通全链路闭环：

| 层 | 内容 | 回答的问题 |
|---|---|---|
| 精准数据与合规层 | 数据合规服务、智能合规融合终端 | 数据能不能用 |
| 端侧算力层 | 边缘设备轻量化算力 | 数据在哪处理 |
| 智能体感知与采集层 | 4D空间记录终端、动作捕捉手套、全身动捕套装 | 数据从哪来 |
| 智能体移动与交互层 | 人形机器人、工业机械臂、无人车、四足机器人等**六大场景** | 数据用在哪 |

靶子是行业最大痛点——**数据孤岛**：各采各的、各标各的，重复建设、格式不统一、无法流通，"机器人越造越多，数据资产越攒越散"。

## 3. 标准组长（最值得关注的信号）

- **2026年7月**：工信部人形机器人与具身智能标委会数据工作组（**WG7**）成立，四维图新任组长单位，CEO 程鹏任组长
- 目标时间表：**2026年中建体系，2027年初出标准**
- 已拉出 **35项标准清单**，四池滚动管理

三层含义：
1. 具身智能数据竞争从"各玩各的"进入"建章立制"阶段
2. 谁定标准，谁就掌握产业数据资产的话语权
3. 数据从"成本项"变成"可流通资产"，前提是有标准

## 4. 商业模式：合规不是公益，是生意

- 2025年智云业务营收 **29亿元，同比 +28.85%**，核心是数据合规
- 客户：宝马、丰田、长城、阿里云、亚马逊云
- 车端合规模式平移到机器人端：机器人摄像头持续采集人脸、位置、室内布局等敏感数据，需实时脱敏、合规审图。孟庆昕："只要机器人工作，我们就提供合规监管"
- 更长远设想：家庭多机器人时代（扫地/擦窗/陪伴/服务），精准时空数据服务可能像车机订阅一样**按月收费**

## 5. 关键引语

- 程鹏："把数据的'成本'变成'资产'，将'孤岛'连成'陆地'。"
- 孟庆昕："只要机器人工作，我们就提供合规监管。"

## 6. 财务面（2026-08-21 补充，多来源）

解读：智云板块（数据合规为核心，约 29 亿营收）是真实增长引擎；但汽车智能化投入产出周期错配导致主业持续失血，表观盈利靠资本运作。**对"数据裁判"故事的战略判断不变，但公司处于重投入换赛道阶段——199 岗的招聘扩张与扣非亏损并存，高薪岗位是战略押注而非利润溢出，入职需评估业务线稳定性。**

## 我的观察（整理者注）

- **资质即护城河**：甲级测绘资质 + 合规工具链是政策性壁垒，互联网大厂和机器人创业公司短期都补不齐——GIS 公司在具身智能价值链里卡住的是"裁判位"而非"运动员位"。
- **商业模式迁移路径清晰**：车端合规（已验证、29亿营收）→ 机器人端合规（增量市场）→ 家庭时空数据订阅（远期想象力），同一套能力吃三个时代。
- **与招聘市场互证**：环天智慧等遥感/GIS 公司给算法岗开出 25-50K、远超传统开发岗，方向一致——时空数据 + AI 的组合正在从"成本中心"（给项目做交付）转为"资产中心"（数据本身可计价流通）。
- 风险点：标准组长身份与商业利益合一，同行是否买账、标准落地节奏（2027年初）能否兑现，是观察这家公司的两个时间锚点。
