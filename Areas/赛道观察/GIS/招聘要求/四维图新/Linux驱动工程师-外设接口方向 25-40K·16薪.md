【Linux驱动工程师-外设接口方向】工作经验：3-5年，本科及以上
岗位职责
负责 Linux/Android 平台 I2C、SPI、UART、GPIO、TP 等外设接口驱动的开发与维护；
负责需求分析、驱动设计、调试验证及相关文档编写；
配合硬件、应⽤团队进⾏问题定位、性能优化与版本交付；
⽀持驱动在不同 SoC 平台上的移植与适配。
任职要求
本科及以上学历，计算机/电子/通信等相关专业；
英语四级以上，良好的读、写能力；
3-5 年嵌⼊式 Linux 驱动开发经验，熟悉设备树、驱动框架、中断、时钟等机制；
熟练掌握 I2C / SPI / UART / GPIO 等外设接口协议及调试方法；
具备扎实的 C 语言基础，能阅读硬件原理图和数据手册；
熟悉 input subsystem 或 TP 驱动者优先；
有 MTK、高通、瑞芯微、全志等平台开发经验者优先。
额外加分项
具备 AI 实践落地经验（含 AI Agent 协同工作经验）者优先；
熟悉飞书生态且有飞书 AI 实践经历，或具备飞书效率先锋认证者，同等加分。
