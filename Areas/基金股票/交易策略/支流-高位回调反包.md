# 支流:高位回调反包(前一轮高位票断板回调后的再启动)

> 2026-09-23 立项。源起:澳弘电子(605058)案例——五连板(0911~0917)断板后回调两日(-7.7%),0921尾盘异动,0922反包板,0923低开高走再封板;信号日尾盘买入两日约+26%,且入场点在全天最低之后。与之对照:五连板当日追板中间要扛-7.7%浮亏,晋级预测路径(次日竞价/打板)只能吃到后段。

## 一、策略定义

**对象**:前一轮连板高度达到门槛的票(初值≥4板,待样本定),断板后进入回调观察,捕捉"回调结束、资金回流"的再启动。赚的是反包板与反包后延续的钱,不是晋级的钱。

**与五虎晋级的边界**(为什么独立成支流,不并入五虎):
- 五虎预测"今日涨停的票明日能否再板";本支流做"断板回调后的再启动"。信号日对象**没有涨停**,根本不进五虎的预测分母
- 买点结构:尾盘低吸/反包日确认,非竞价追板;失败情形是"回调变退潮",止损逻辑与晋级失败不同
- 连板高度从日K独立重算,不读五虎池表(支流互不引用;共享判定下沉段库)

**立项判断记录(2026-09-23,用户原话)**:这种走势是无数因子共同作用的结果——板块轮动、市场资金总量、市场情绪、个股股性。因此本支流**先攒样本,后定参数**:下表全部参数均为单样本假设,样本≥20前不允许写死。

## 二、段的组装(方法段)

状态机:**高位断板日 → 回调观察(第1~N日) → 尾盘异动(信号日) → 反包板(确认日) → 延续/兑现 → 退潮(排除/止损)**

| 段 | 判定 | 参数(全部待样本校准) |
|---|---|---|
| (复用)连板高度 | 前一轮最高连板数,日K独立重算 | ≥4板(澳弘5板) |
| 前高观察名单 | 高度达门槛的票自动进本支流观察池 | — |
| 回调深度带 | 自断板前收盘的最大回撤 | ≤8%(澳弘-7.7%;更深=退潮排除) |
| 回调天数窗 | 断板日到反板日的交易日数 | 1~3日(澳弘2日) |
| 量能不塌 | 回调期量能相对板上量级 | 澳弘回调期与板上持平(25万手级);比例阈值待定 |
| **尾盘异动段**(新造,待建) | 横盘日后14:00起放量拉升:拉升幅度+尾盘量占比+站上分时均价线 | 澳弘:25分钟+7.9%,尾盘30分量占全天18%(此前每日常态≤2%) |
| 反包日质量 | 反包板封板方式:沿均价线稳步上行封板(非开盘直线秒板) | 定性,待量化 |
| 板型前提 | 前一轮板的成交形态:换手板vs一字板 | ~~一字排除~~6个月106例无区分度,不作硬条件;更细粒度(板内缩量程度)待研究 |
| (复用)板块因子组/梯队环境 | 断板日与信号日的板块、大盘环境 | 关联待建;环境因子(轮动位置/市场总量/情绪)是用户点名的背景变量 |

个人段:可买门槛只标注(高位票单价高,"一手>8000元"标注不删信号),三禁令同总纲。

## 四、验证标准

- **分母:所有"前高达门槛后断板"的票,含未反包的**(对照组就是失败样本,不选样统计)
- 核心统计:①尾盘异动信号→次日反包率 ②反包后1/3/5日收益(信号日收盘价与反包日开盘价两种成本口径) ③回调深度/天数/量能/板型四条件的区分度(条件命中组与未命中组的反包率之差)
- 样本≥20才允许定参数;当前正样本1个(澳弘),进行中1个(华瓷)
- 历史分钟数据只有约12个交易日可回溯(腾讯5分钟线),**尾盘异动段主要靠引擎前瞻采集验证**,历史样本先验证日K层(回调结构+反包结果)

## 附:案例记录

### 案例1:澳弘电子(605058,元件)——正样本,路径完整

| 阶段 | 日期 | 数据 |
|---|---|---|
| 第一轮五板 | 0911~0917 | 33.31→48.76,每板10~26万手**换手板**,从无一字;板型演进:首板早盘封→2板烂板回封→3板上午封→4板秒板一字→5板高开砸5%再拉板(天量分歧) |
| 断板日 | 0918 | 冲50.62试6板失败,阴跌收47.40(-2.79%),量26.2万手(全程最大) |
| 回调最低 | 0921 | 早盘9:40探45.02(**与5板日最低45.00双底**),随后46~47横盘4小时 |
| **尾盘异动** | 0921 14:10~14:30 | 46.26→49.91(+7.9%/25分钟),尾盘30分钟量4.6万手占全天18%(常态≤2%),收48.43站上均价线2.4% |
| 反包板 | 0922 | 平开,沿均价线稳步上行,11:25封53.27,午后开板一次立即回封,收在均价线上方4.5% |
| 延续 | 0923 | 竞价低开-1.2%,开盘5分钟+7%,前30分钟量占64%,13:45封死58.60,封后零量 |

回调量化:收盘口径-7.7%(48.76→45.02),2个交易日;回调期量25.5万手与板上持平。
收益对照(至0923封板价58.60):尾盘异动起点买46.3=+26.4%(无浮亏);0921收盘买+21.0%;0922开盘买+20.8%;追5板48.76持4天+20.2%但中间浮亏-7.7%;0923竞价买+11.4%(注:竞价低开按现行五虎规则会"排除",本例是该规则反例,记入校准数据不改规则)。

### 案例2:华瓷股份(001216)——板型对照实验,断板第1天(0923收盘确认)

前一轮**6连板**(0915~0922),其中0921/0922为缩量一字(量仅2.1/1.8万手,此前放量板22.9~28.1万手)。0923断板:开27.66(+4.5%,全天最低),触涨停价29.12未封,尾盘收28.55(+7.86%),**成交55.6万手=前日一字的31倍**;竞价9:20后有大卖单冲击(竞价卖单冲击检测已捕获报警)。与澳弘0918的关键差异:华瓷断板日**最低点都没跌破6板收盘价**(回调深度0,收+7.86%对澳弘断板日-2.79%)——分歧剧烈但承接更强,真正的回调测试从0924开始。
**观察点**:①若随后1~2日浅回调+尾盘异动+反包→板型前提放宽(一字板后回调也可接);②若直接退潮→"缩量一字加速后的回调不接"成立;③若明日直接回封=7板,则根本不进本支流对象(走了空间板压制的反面)。**15:35五虎任务已确认转"断板观察"(断板第1天)**——本支流的观察名单事实来源先手工盯住:华瓷、内蒙新华(5板,断板第1天)、南华生物(4板,断板第1天)、锡华科技(4板,断板第3天,浅回调-6.8%但未反包的活反例)。

初步区分度(样本≤4例,只作方向参考):
- **回调深度是最强分水岭**:策略窗组深度中位-7.7% vs 慢/未反包组中位-20.5%
- **高度门槛有意义**:≥4板+浅回调(≤10%)4例中2例反包;3板+浅回调6例中仅1例
- **一字率方向**:策略窗4例一字率全部0%(全换手板);高一字率案例(瑞尔特75%/亚盛50%)全部深幅退潮——支持"换手板前提",待更多样本

**统计诚实注记**:上表"策略窗收益"是按"反包≤3日"**事后分组**的条件收益,不是事前可知;事前可知组合(前高≥4板+回调≤10%)当前命中率2/4。把命中率做上去的关键假设是**尾盘异动信号**(分钟级历史仅约12个交易日,无法历史回测,只能引擎前瞻采集验证)。东财池只留约15个交易日,样本扩容依赖全市场日K回补后重扫。
