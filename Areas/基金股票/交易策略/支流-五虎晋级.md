# 支流:五虎晋级(涨停晋级预测)

> 源起第一句"追涨停板"的数字化。2026-09-22 文档化首版(一期已上线,实时档位已细化待实现)。

## 一、策略定义

**预测昨日涨停的股票今日能否继续涨停(晋级),并在盘后/竞价/盘中三个时点给出分级判断。**
本质是期望值游戏:赌的不是"明日必涨停",是**次日溢价期望为正**;排队买不进的涨停(一字板)没有执行价值,故同时评估排队性价比。

三个判断时点:
1. **盘后**(15:35):昨日涨停池全体按十七因子打分,产出明日晋级面板(重点/普通/排除)
2. **竞价**(9:20/9:25):竞价定型对档位做第一次修正(虚假挂单识别)
3. **盘中**(二期):实时档位重算(已细化待实现)

## 二、段的组装

**方法段**(进打分,影响晋级率统计):
封板换手率、封成比、首封时间、炸板次数、板块厚度(同板块涨停家数)、梯队环境(全市场涨停数/炸板率)、辨识度(全市场最高板/板块最高板/并列)、连板高度、几日几板密度、队列消耗比(单独输出不并入总分)、缺口天数(连续一字数)

**个人段**(只标注):可买门槛(创业板30/科创板68/北交所43/83/87/92标"⛔无权限",不参与档位)

## 三、池子进出标准

- **进入**:当日收盘涨停(新票入池或连板数+1);已移出票再涨停开新周期
- **保持**:断板第1、2个交易日转"断板观察",继续预测(反包是重要形态,必须留在分母)
- **移出**(任一):断板超过2个交易日 / 收盘跌停 / 断板观察期收盘较最后涨停日收盘回撤≥15% / 停牌
- 参数理由:反包与二次启动绝大多数发生在断板后两日内;超期票的短线关注度已衰减。观察天数与回撤阈值为可配置项,攒数据后校准。

## 四、打分规则(第一版,先验权重,攒两周核实数据后校准)

| 因子 | 给分 |
|---|---|
| 封板换手率 | <10%→4 / 10~20→3 / 20~30→1 / >30→0 |
| 封成比 | >3%→3 / 1~3%→2 / <1%→1 |
| 首封时间 | 9:30~9:45→3 / 9:45~10:30→2 / 10:30~14:00→1 / 14:00后→0 |
| 炸板次数 | 0→2 / 1→1 / ≥2→0 |
| 同板块涨停家数 | ≥5→3 / 3~4→2 / 1~2→1 |
| 全市场涨停家数 | ≥80→3 / 50~80→2 / <50→1(炸板率>30%时降1分) |
| 辨识度 | 全市场最高板→3 / 板块最高板→2 / 同高度并列→1 |
| 连板高度 | 1~3板→2 / 4~5板→1 / >5板→0 |

**档位**:≥14重点 / 8~13普通 / <8排除。断板观察成员照算分但档位强制排除。
**竞价修正**(9:25定型后):定型涨停且9:20仍顶→上调一档;定型涨幅≥3%→维持(含8%~未顶板的20cm票,高开不惩罚);9:20顶板但定型<3%(虚假挂单)→下调一档;平开/低开→排除。涨停阈值:主板9.8/创业科创19.8/北交所29.7/ST股4.8。

## 五、验证标准

- **分母**:昨日涨停池全体(含断板票),不加任何个人约束过滤
- **结果三分类**:晋级(今日涨停收盘)/触板未封(炸板池)/断板(两者皆无)
- **核实**:每日15:35自动对昨日预测逐票核实落库;三档晋级率+因子分桶晋级率(样本≥5才显示)
- **调参门槛**:单因子分桶样本≥20才允许改该因子权重;改后重放最近可回放历史对比
- **已知待校准**:第一版规则对首板打分偏宽(0921重点96/160,区分度不足),两周数据后收紧

## 附:关键机制备忘(打板常识,写给未来的自己)

- 一字板排队:集合竞价未成交申报带时间戳进连续竞价;成交边界=队列被啃深度;封单厚=买不进,能买到常是危险信号
- 同高度≠同梯队:溢出资金认题材与辨识度,不认板数;题材不同的同高度票互不为替补
- 竞价顶板三段论:9:20前可撤(零成本诱多)/9:20后不可撤(见真章)/9:25定型(投票结果)
