# 根据地 + 雷达:板块作战策略

## 一、核心原则

**全盘观察,但只做熟悉的板块或当前叙事性强的板块。**

- **雷达常开**:14 个方向的池子 + `/stock 板块轮动` 每日一扫,全局盘面始终在视野内;
- **重仓聚焦**:真金白银只投向两类板块——①自己拆得透的(熟悉度)②叙事正强、资金持续流入的(景气度)。两者最好兼备,缺一则降仓。

## 二、为什么这么做

- 散户的优势不是快,是**"懂了才拿得住"**:回调时,熟悉的板块敢补仓,不熟的只能割肉——执行质量由熟悉度决定;
- 追轮动是散户亏损头号来源:**看到"轮到X"时通常是行情后半段**(实证:9/3军工板块涨幅第一,9/4直接垫底);
- 纯单板块不看雷达也不行:板块寒冬三年等一场空。所以是"根据地+雷达",不是二选一。

## 五、雷达使用规程

| 轮动表信号 | 动作 |
| --- | --- |
| 低位回升(今日+、5日-) | 列入观察,不动手;根据地方向出现此信号=准备加仓 |
| 延续强势(今日+、5日+) | 根据地方向=持有/加仓窗口;非根据地方向=只看不动 |
| 高位回落(今日-、5日+) | 减仓/止盈信号,根据地方向触发则执行 |
| 延续弱势 | 无视 |

**频率纪律**:调仓月度级,盘中不动手;单一方向单日涨幅>4%当日禁止追入(情绪税)。

### 盘中战术(ETF时代专属能力,联接基金做不到)

**背景**:行情是探出来的,没有谁说得准——祖训("高开低走""周末利好周一蹲")只是概率倾向,不是定律。ETF 的盘中定价能力,就是用来在概率被证伪时当场行动的。

**进场试探结构**(2026-09-07 通信ETF实例总结):

1. **高开后回踩浅**(回调幅度明显小于涨幅,如+4%回落仅0.5%)= 承接强,祖训失效的信号;
2. **盘中低点逐级抬高**(每次回调的低点 > 前一次)= 有人持续接货的结构;
3. 满足以上两条 → **试探仓进场**(小仓位),而不是等收盘。

**试探仓纪律**(必须同时满足):

- 仓位 = 该方向计划仓位的 1/4~1/3;低点跌破前低立即离场,亏损上限预设;
- 试对(浮盈+结构延续)→ 下一个抬高的低点加到 1/2,再对 → 加满;
- 试错两次 → 当日停止,该方向冷却一天;
- **联接基金时代此节全部作废**——没有盘中价就没有试探的资格,这正是开股票账户的核心理由。

## 六、变盘确认清单(判断"行情来了")

1. 领涨方向全天量能显著放大(如515880 ≥30亿)且收盘保住涨幅;
2. 两市成交 ≥2.1万亿;
3. 次日不回吐(放量长阳次日阴跌一半=假信号);
4. 三日内有兄弟板块接棒(轮动表"延续强势"扩散)。

四条中三条满足才算变盘成立,按加仓计划执行;不满足则维持"横盘震荡假设"(见 [[策略]])。
