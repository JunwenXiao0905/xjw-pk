# 支流:稳步爬升

## 一、策略定义

捕捉沿20日均线温和上行、量价健康、尚未加速的波段标的,作为低吸底池。与尾盘六条(短线博弈)互补,持股周期以周计。

## 二、段的组装

| 条件 | 段 | 参数 |
|---|---|---|
| 20日均线向上(近5个交易日斜率为正) | 均线段(MA20) | 周期20,回看5日 |
| 10日窗口内阳线≥7根 | 阳线计数 | 窗口10,最少7 |
| 窗口累计涨幅10%~40% | 涨幅带(窗口口径) | [10,40]% |
| 窗口最大回撤<8%(收盘口径) | 回撤段 | <8% |
| 当日换手1%~15% | 换手带 | [1,15]% |

个人段:无(本支流不涉及权限约束,可买门槛在出口闸统一)。

- 分母:有完整日K的池内标的(当前仅40只有K线——**数据债**,全市场K线回补后分母扩至全A)
