# 板块观察

> **定位**:回答"现在盯什么、什么时候动手"——[[交易策略/根据地+雷达-板块作战策略]] 里雷达一节的落地清单。
> 与 [[ETF股票池]] 的分工:**股票池是注册表**(有什么可买,慢变),**本文是观察黑板**(正在盯什么,周级变化),[[每日信息]] 是日志(每天干了什么)。
> **更新节奏**:每周日例行 + 轮动信号突变时;信号快照可直接从 daily.py 生成的 [[每日信息]] 当日「板块轮动」表抄。

## 观察纪律

- 每个条目必须有四件套:**叙事(为什么盯)/ 信号快照 / 触发条件(怎么算可以买)/ 移出条件(怎么算看错)**,缺一不收录;
- 同时观察 **≤ 5 个**——超过说明没有重点;
- 观察板块的资金上限 = 雷达仓(总资金 ≤10%),想转正必须走 [[ETF股票池]] 的定调流程(拆持仓、比费率、过准入标准);
- 个股试探一手起步,记录进 [[ETF股票池]] 的股票观察池。
