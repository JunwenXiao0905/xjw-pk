## 主链路

```text
客户端
-> DNS
-> TCP / QUIC
-> HTTP / HTTPS
-> 路由
-> 参数解析与校验
-> 认证
-> 业务逻辑
-> 数据库 / 缓存 / 消息队列
-> 响应
```
